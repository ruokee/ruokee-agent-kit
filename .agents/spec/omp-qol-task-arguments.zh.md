# QoL 任务参数

## 目标

在宿主校验前清理符合条件的内建 task 调用中的不兼容字段，保留其他所有参数及原生任务行为。本调整遵循组件共同的配置、激活、状态和隔离要求。

## 公共面

### 配置

| 键 | 默认值 |
| --- | --- |
| `taskArgsEnabled` | `true` |

### 状态

`/qol` 的任务参数行显示本次激活的改写调用次数。

### 任务参数

只为 schema 暴露 `sourceSession` 的内建 `task` 在宿主校验前执行清理。工具缺失报告 `unavailable`，被遮蔽报告 `incompatible`。schema 缺少该字段时报告 `unavailable` 和 `task-tool-without-seance-fields`，保留普通 `model` 选择器及投机启动。

扁平调用视为一个条目，`tasks` 数组视为批次。对 `agent` 为字符串、trim 后非空且不等于 `seance` 的对象，删除其自有的 `sourceSession`。宿主缺少普通按调用选模型能力，或当前 task 禁止此能力时，还删除其自有的 `model`。后者包括 `off` 和 `eval`。被删字段的值不影响清理。

每次调用读取所属会话的许可，各并发会话独立判断。宿主区分维护者授权层与有效设置层时，两层都须允许 task 按调用选择模型。其余宿主使用有效模式。允许选择时保留 `model` 原值与结构，交原生校验及授权。具备该能力而设置不可读时，也保留 `model` 交原生处理。宿主设置保持原值。

保留 Agent 缺失、空、仅空白、非字符串及 `seance` 的条目，保留非对象条目、批次级字段和其他所有参数。不推断默认 Agent。一次改写调用计数增加一次，多项改写也只计一次。无变化不计数。符合条件的 model-only 项在选择关闭时计为改写，在选择开启时保持原样。

宿主显示、执行并持久化当前 assistant 的修订后参数，因此后续请求和会话文件会看到清理后的调用。不重写更早历史，不新增会话条目。保留原生 task schema、描述、审批、派发、后台生命周期和结果渲染。调用因其他原因仍无效时仍失败。多个扩展修改输入时，以宿主采用的最后一个修订为准。

接受的代价是在清理注册期间禁用任务投机启动和实验性读取投机，包括未改动的调用。不修改宿主设置本身。关闭模块后，下次激活恢复原生行为。缺少 `sourceSession` 的 schema 不承担此代价。宿主改变字段含义或范围时需要重新评估，不能猜测并扩大清理范围。

## 验收标准

- 符合条件的扁平及批次调用删除各适用项自有的 `sourceSession`。旧宿主和 task 选择关闭时还删除 `model`，使任务使用 Agent 配置的模型。允许选择时保留该字段。seance 项、排除的 Agent 形态、缺失的目标字段、非对象项、批次顶层字段及无关参数保持不变。
- `off` 和 `eval` 模式下，符合条件的 model-only 调用删除该字段并增加改写计数。允许选择时，此类调用保留参数及计数。保留的未支持或未授权模型选择返回原生错误。
- task 选择许可的变化对后续调用生效。每个调用所属会话的有效设置及维护者授权层决定各自结果。具备能力而设置不可读时，保留 `model` 交原生处理。
- 发生改写的一次调用无论改动多少项，计数只增加一次。显示、执行及持久化的当前参数包含同一清理结果；因其他原因无效的调用仍由原生校验拒绝。
- 关闭清理、工具缺失或被遮蔽、schema 不含 `sourceSession` 时，原生参数及行为不变。只有 model 的 schema 保留普通选择器及推测启动。
