# 请求对齐

## 目标

规定 Remote 和 Handoff 对齐共同遵循的内容复用、隔离、失效和失败要求。两者复用同一会话普通请求中已证明的共同内容，协议资格、允许的修复、原因及收益证据保持独立。

## 非目标

拥有 Pin、用量或模型规则状态；重新运行处理器以重建已发送结果；修改普通或非目标请求；接管原生维护或其他扩展所有权。

## 公共面

对齐是可选能力。拒绝改写时完整原生请求保持不变，不阻断、延迟或丢弃。各能力分别报告参照确认、操作绑定、候选校验和实际发送。物理发送与重试在传输时各计一次，不按载荷准备计数。拒绝仍计入总数；Remote 关闭或不可用不使 Handoff 不可用，反之亦然。

## 不变量

### 普通请求参照

只有已确认的普通主循环发送能提供可复用参照。原始来源、完成的准备、处理器结果及实际出站载荷必须属于同次发送，并原样到达传输层。标题、预热、advisor 和 Handoff 请求不建立普通请求参照。Handoff 还要求准备结果携带工具集合。

主会话、原生 task 子会话和 Eval 子会话分别保留参照和计数。复用必须保持会话归属、持久身份及 Provider 身份、有效模型和 API、工具、系统提示词、思考状态及发送身份。模型名、文本、端点、缓存键或时序相等不能证明会话归属。

原生 CLI 和 SDK 会话来源必须经过确认，不能为任意 Agent 实例推断来源。来源未知或变化后，完整来源证明仍可支持复用，但长度或输出相等不能证明局部独立性。依赖历史的图片准备以及后续日期或 cwd 提醒，在未确认局部依赖时需要完整范围证明。

### 操作生命周期

原生操作在整个生命周期内使用第一个符合条件的参照，包括初始没有参照的状态。之后的普通工作、处理器状态变化、认证刷新和传输重试都不能替换参照。

会话切换、分支或树导航开始前撤销受影响的旧参照资格。原生转换结束后，无论成功、失败还是取消，新的普通工作都可以建立后续资格。模型、工具、系统提示词、思考配置、历史、取消、压缩提交或会话生命周期变化使相关工作失效。晚到响应、重试或恢复旧值都不能复活它。

自动维护可以在工具循环步骤间提交历史，而不改变本次运行的取消信号。新的普通发送可以用自身当前身份与凭据、准备结果及最终发送建立新参照，但不能复活旧操作。只有新的原生操作能使用新参照。身份歧义、已取消信号或较早发送关联的凭据不能建立资格。

### 内容复用

完整保留来源范围时，可以复用其已确认处理结果，即使来源消息重复。局部复用还要求可独立提取的已发送单元、该单元全部保留的依赖，以及未改变的处理条件。输出、位置、长度或来源标记相等均不足以证明。不得再次运行黑盒上下文或请求处理器来获得证明。

不透明历史保持不透明。原生裁剪、已删除依赖、工具调用与结果配对、图片历史和新增尾部保持原边界。不得恢复已删除工具输出，也不得假定尚未建立的纯投影合同。

### 发送

每条物理请求最多一个对齐改写方。Remote V2 证据不赋予 Handoff 资格。载荷回调结束后，最终请求仍须满足必要证明。完整应用校验通过的修复，或完整保留原生正文并给出固定原因。必要证明失败时不得部分发布候选。相同候选为 `already-aligned`，保留原有序列化结果。

兼容激活共享观察，不重复拦截或计数。不兼容对齐合同报告 `coordinator-conflict`，不得复用或修改他方状态。一项能力失败或缺少接口时，另一项仍可使用。

### 原生归属

触发、准备、裁剪、投机、凭据、取消、重试、回退、采用、提交和续接归 OMP。不增加压缩入口、`session_before_compact` 拦截、虚构摘要或重试。压缩否决仍归安装它的组件。

保留原生参数、接收者行为、结果、异常、取消信号及对外可观察属性行为。子会话结束或替换只释放该子会话资源。清理只释放本包仍拥有的资源，保留他方替代项。没有注册需要共享资源时释放它。不保留已结束操作或过时参照。在途工作归运行进程；设置或注册变更在重启 OMP 后生效。

## 验收标准

- 相同模型的并发会话保持隔离，包括 task、Eval 子会话，以及取消、替换和恢复活动。
- 只有已确认的普通发送建立参照。普通及非目标请求正文不变，各处理器执行一次。
- 失效永久撤销旧操作。新的普通工作只恢复未来资格，包括运行信号未变的续接。
- 完整范围和局部单元分别满足对应证明要求，不恢复裁剪内容，不解释不透明历史。
- 独立关闭、拒绝或不可用状态保留原生请求和另一对齐能力。每条物理发送最多一个改写方，并只计一次。
- 清理保留外来所有权及原生行为，只释放离开会话的资源。
