# 请求对齐

[English](./request-alignment.md) | 中文

## 目标

让 Remote 和 Handoff 复用同一会话普通请求中已证明的共同内容。共享观察和传输协调，不合并协议资格、原因或收益证据。

## 非目标

拥有 Pin、用量或模型规则状态；重复执行处理器以重建已发送结果；修改普通或非目标请求；接管原生维护或竞争包装。

## 公共面

[主规范](./README.zh.md)维护配置和状态。[远端](./remote.zh.md)与 [Handoff](./handoff.zh.md) 分别维护适用和修复规则。拒绝改写后仍发送完整原生请求，不阻断、延迟或丢弃请求。

## 不变量

### 普通请求参照

参照包含同次普通主循环发送的原始来源、完成的准备、回调和实际出站载荷。确认这些内容属于同次发送，并原样到达传输层。标题、预热、advisor 和 Handoff 请求不建立普通请求参照。Handoff 还要求准备结果携带工具集合。

每个实际 AgentSession 分别登记有效模型、API、工具、提示词、持久身份、Provider 身份、发送编号及有效代次。有效代次以 `epoch` 表示，用于区分该会话参照的有效范围。模型、文本、端点、缓存键或时序相等均不能证明会话归属。主会话、原生 task 子会话及 Eval 子会话分别维护参照和计数。

在 `session_start` 前观察原生 CLI/SDK 构造发布，持续核对原 agent、runner 和 stream 身份。这不是认证任意 Agent 实例的接口。未观察或构造链变化时仍可保留完整范围证明，但不能凭长度或输出相等取得局部原生独立性。依赖历史的图片准备及后续日期、cwd 提醒，在局部依赖未证明时需要完整范围证明。

### 操作生命周期

每个原生操作在整个生命周期内冻结初始参照，包括没有参照的状态。后续普通工作、处理器状态变化、认证刷新和传输重试均不能替换它。

切换会话、分支或树导航前先撤销旧有效代次。原生转换结束后，无论成功、失败还是取消，新的普通工作均可恢复后续资格。模型、工具、系统提示词、思考配置、历史、取消、压缩提交及会话释放使相关事实失效。晚到响应、重试或恢复旧值均不能复活失效工作。

自动维护可在工具循环步骤间提交历史，而不改变运行信号。新的普通发送将自身凭据解析器绑定到当前有效代次、准备结果及最终发送，在恢复会话参照时永久保留旧根操作的撤销状态。只有新操作根可捕获恢复后的参照。身份歧义、已取消信号或较早发送的解析器仍不具资格。

### 复用

先证明完整保留的来源范围，再尝试局部复用。重复来源消息不破坏完整证明。局部复用要求可独立提取的已发送单元，以及全部保留的依赖和处理条件。输出相等、位置、长度或来源标记均不足以证明独立性。不得重复执行黑盒上下文或请求处理器。

不透明历史保持不透明。原生裁剪、删除的依赖、工具调用及结果配对、图片历史和新增尾部保留原边界。不恢复已删除工具输出，不虚构纯投影协议。

### 协调

使用一个进程协调器、独立会话登记、同次普通发送的不可变事实，以及每个原生方法或实际模型注册表的一层包装。一条物理请求最多一个改写能力。V2 证明不赋予 Handoff 资格。一项能力拒绝或缺少接口时，另一项仍可使用。

协调器和激活记录携带合同版本。外部版本既不复用也不修改，报告 `coordinator-conflict`。激活快照使用当前合同版本自身的进程级键。

构造完整候选，在载荷回调结束后的最终传输处校验，再原子替换。相同候选视为已对齐，不重新序列化。证明不足时保留完整原生正文并给出固定原因。统计实际传输委派及重试，不统计载荷回调；计数独立且有界，拒绝仍计入总数。

### 原生归属

触发、准备、裁剪、投机、凭据、取消、重试、回退、采用、提交和续接归 OMP。不新增压缩入口、`session_before_compact` 处理器、虚构摘要或重试。压缩否决归安装它的组件。

保留原生参数、接收者、结果、异常、信号及仍持有属性的形状。子会话结束或替换只释放其自身登记。只恢复本包仍持有的包装，不恢复竞争包装。最后一个登记结束后释放共享资源。只保留当前参照及活跃操作可达的快照。在途参照留在运行进程中，设置或注册修改并重启 OMP 后才退出。

## 验收标准

- 相同模型的并发会话保持隔离，包括 task、Eval 子会话，以及取消、替换和恢复。
- 只有已确认普通发送建立参照。普通和非目标正文不变，处理器只执行一次。
- 失效永久撤销旧操作，新的普通工作只恢复未来资格，包括运行信号不变时的续接。
- 独立关闭及拒绝改写均保留原生请求和另一对齐能力。每条物理发送最多一个改写方且只计数一次。
- 清理保留外部包装及原生方法行为，只释放离开会话的资源。
