# QoL 回复复制

## 目标

通过固定交互快捷键复制最后一条 assistant 回复的文本。本调整遵循组件共同的配置、激活、状态和隔离要求。

## 非目标

复制选区、思考、工具调用、工具输出、图片，或提供 `/copy` 命令、可配置键位及剪贴板历史。

## 公共面

### 配置

| 键 | 默认值 |
| --- | --- |
| `copyEnabled` | `true` |

### 状态

`/qol` 的复制行显示实际固定键 `alt+shift+a`。

### 复制回复

在交互宿主读取扩展快捷键前绑定 `alt+shift+a`。每个扩展绑定拥有自身注册；会话 journal 切换保留已有绑定。在 pending、disabled 或 invalid 状态中，该键在绑定生命周期内仍被占用，但处理器不动作。与其他扩展的按键冲突由宿主裁决，本模块不处理。

启用且空闲时，选择当前分支最后一条 assistant 消息，跳过没有内容的 aborted 消息。把该消息的 `text` 块无分隔符拼接并去掉首尾空白。结果非空时通过宿主剪贴板助手复制。最后一条消息只有思考、工具调用或其他非文本时不复制，不回退到更早回复。不得写空字符串或复制非文本块。

忙碌时提示并保留剪贴板。没有可复制回复时提示且不写入。宿主助手通过 OSC 52 和原生剪贴板工具尽力写入，并吞掉写失败。助手正常返回后报告成功，即使底层写入实际失败。复制抛错时捕获并报告一次，不重试、不回退到文件，也不在通知中显示复制正文。复制不新增会话条目，不启动请求。

## 验收标准

复制检查覆盖最后消息选择、拼接与去空白、空 aborted 消息、非文本排除、不回退、停用及忙碌状态、无文本及剪贴板错误、按键及时可用和 `/qol` 的实际键位。
