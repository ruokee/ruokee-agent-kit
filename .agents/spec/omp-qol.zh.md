# omp-qol

## 目标

在一个包中提供六项独立开关的 OMP 调整：持续等待任务、主会话错误恢复、实验性压缩期限延长、恢复会话时重放原生历史、任务参数清理和复制最后回复。共用安装与配置入口，分别展示有效状态、设置和失败原因。

## 非目标

- 替用户安装或迁移，修改已安装宿主文件、其他扩展或无关宿主行为。
- 只含消息的续等、按进程名等待、只含服务的续等，或用轮询模拟这些能力。
- 改变轮内原生重试、提供方选择、宿主错误分类器或子代理恢复。
- 匹配提供方错误正文、恢复全部错误、工具恰好执行一次、回滚或幂等续跑。
- 远端请求对齐、压缩用量或模型规则。这些属于 `omp-smart-context`，QoL 不激活也不停止它们。
- 复制选区、思考、工具调用、工具输出、图片，或提供 `/copy` 命令、可配置键位及剪贴板历史。

## 公共面

### 配置

使用 `@ruokee/omp-qol` 的 OMP 插件设置，项目值覆盖用户值。每次激活只读取一次有效设置。修改后重启 OMP 生效；在同一个运行进程中创建另一个会话，不刷新该快照。

全部开关及通知字段均为 boolean。完整键名与默认值如下：

| 键 | 默认值 |
| --- | --- |
| `enabled` | `true` |
| `waitEnabled` | `true` |
| `waitContinueEmptyWindows` | `true` |
| `waitJobsSeconds` | `1200` |
| `waitMessagesSeconds` | `1200` |
| `waitProcessSeconds` | `1200` |
| `recoveryEnabled` | `true` |
| `recoveryMode` | `knownTransient` |
| `recoveryMaxAttempts` | `8` |
| `recoveryBackoffBaseMs` | `1000` |
| `recoveryBackoffMaxMs` | `8000` |
| `recoveryNotify` | `true` |
| `compactionTimeoutEnabled` | `false` |
| `compactionTimeoutMs` | `900000` |
| `compactionTimeoutFloorMs` | `300000` |
| `compactionWindowGuardMs` | `3600000` |
| `compactionTimeoutNotify` | `true` |
| `replayEnabled` | `true` |
| `taskArgsEnabled` | `true` |
| `copyEnabled` | `true` |

数值和枚举约束如下：

- 三个等待时间设置接受 `0.05` 至 `3600` 秒的有限数值。`waitMessagesSeconds` 和 `waitProcessSeconds` 仍校验，但在受支持宿主中不起作用。
- `recoveryMode` 只接受 `knownTransient` 和 `unclassified`。`recoveryMaxAttempts` 是 1 至 8 的整数。
- `recoveryBackoffBaseMs` 是 1 至 10000 的整数。`recoveryBackoffMaxMs` 是大于基值且不超过 10000 的整数。
- `compactionTimeoutFloorMs` 是 300000 至 3599999 的整数。`compactionTimeoutMs` 是大于该下限且不超过 3600000 的整数。
- `compactionWindowGuardMs` 是不小于有效 timeout 且不超过 14400000 的整数。

缺少键时取默认值。显式 null、类型错误、非有限数值、整数项中的小数、越界值或未知枚举只停用所属模块。未知键、非对象设置根、读取设置失败或非法总开关 `enabled` 停用全部模块。拒绝整个设置对象后，不用默认值激活模块。

`compactionCacheEnabled`、`compactionCacheProvider`、`compactionCacheMode`、`compactionUsageEnabled`、`modelPromptsEnabled` 不存在，按未知键拒绝整个配置，不提供兼容别名。迁移要从用户及项目作用域移除这些键，保留无关设置和有效启用结果，并取得单独授权。

诊断只列拒绝的键与规则，不回显值。每项模块原因每次激活通过宿主日志报告一次，有 UI 时也通过 UI 报告。总开关约束全部模块动作；复制快捷键在扩展绑定存续期间仍被占用，即使动作已停用。

### 状态

`/qol` 只读，不启动模型轮次。展示包身份和版本、激活 cwd、重启刷新政策、设置有效性，以及六个模块的状态和有效配置。会话开始前使用 `pending`，区分 `enabled`、`disabled`、`invalid`、`incompatible`、`unavailable`，附有界原因码。部分或全部设置被拒时列出键，不显示值。

等待行显示 `entry=wait`、`effectiveDefaultSeconds`，并将 `messageContinuation`、`processWait`、`serviceContinuation` 标为 `not-applicable`。恢复行显示模式、次数上限、基值、封顶值和通知开关。压缩行显示 timeout、floor、guard、通知开关和实际进程级状态。重放行显示实际进程级状态和改写次数。任务参数行显示本次激活的改写调用次数。复制行显示实际固定键 `alt+shift+a`。

### 持续等待

只扩展可识别的独立内建 `wait` 入口。入口缺失、属于他方、结构无法识别或缺少必要宿主能力时保留原生行为，并报告有界原因。保留原生读取审批、严格校验、可中断性和必要工具加载行为。

公开可选参数 `timeout` 接受 `(0, 3600]` 秒的有限数值，决定本次调用总期限。省略时使用 `waitJobsSeconds`。工具参数的下限不是配置项的 `0.05` 下限。

`waitContinueEmptyWindows=true` 时，只有原生结果标明空窗口、任务列表非空且全部任务仍在运行，才在同一次调用内续等。判断宿主结构化结果，不判断正文。消息、已结算任务、无任务、错误、steering、中断、取消、未知结果结构和服务事件立即返回。开关为 false 时返回第一个原生窗口。

总期限只结束当前等待调用，不启动或取消任务及进程，不在原生等待之外消费消息或结果。调用者取消优先并保留自身原因。即使期限已到，随后到达的原生结果仍胜出并原样返回。只有本次期限已经到达，且拒绝属于宿主已知中止 `ToolAbortError`、`AbortError` 或精确消息 `Operation aborted` 时，才转成期限结果。其他错误原样抛出。

期限到达而没有终态结果时，返回最后一个确定的全运行窗口及有界期限说明；没有此类窗口则返回最小说明。说明指出可再次调用 `wait` 或使用 `proc://`。全部退出路径释放当前调用的等待资源。

### 错误恢复

只恢复最后一条 assistant 消息为 `stopReason: "error"` 的主会话运行，包括原生重试结束后仍存在的错误。成功输出引用错误文字仍是普通输出。缺少必要恢复接口或开关关闭时保留原生行为。不得改动原始 assistant 错误。

`knownTransient` 接受宿主分类为 `Transient` 或 `Timeout` 的错误、`stopDetails.type` 为 `stream_interrupted_after_content` 的错误，以及同时没有 HTTP 状态和分类结论的错误。未分类指宿主错误 ID 为零或在其 class mask 之外。无状态未分类错误不需要中断标记。`unclassified` 接受瞬时、超时和全部未分类错误，受相同排除规则约束；中断标记不扩大该模式范围。

两种模式都排除内容阻断、用户中断、abort、silent abort、认证失败、OAuth 过期、用量限制、账户策略、上下文溢出、payload 拒绝、grammar 拒绝、不支持的模式、thinking loop、过时的 responses item 和确定性工具 JSON 错误。HTTP 4xx 中除 408 与 429 外均为终止状态。排除项和终止状态优先于模式及中断标记。

使用默认开关与模式时，下列 assistant 错误根据宿主字段符合恢复条件，除非取消、排除项、终止状态或任一上限阻止续跑：

```text
Error: Upstream provider closed the connection before the response completed: stream ended without terminal event or completed response
```

不经新用户消息，在同一主会话继续。尝试次数从 1 开始，每次等待 `min(base × 2^(attempt - 1), max)` 毫秒。每链预算与退避跨模型运行保留。宿主独立的每链 8 次续跑上限仍生效。只有本模块实际请求的续跑计入次数。同一运行和轮次的重复停止事件不增加等待或续跑。

正常完成、范围外错误或取消结束当前链。之后的独立链使用新预算。其他 stop hook 的续跑不继承本模块已经耗尽的预算。新运行、会话切换、关闭或原链失效阻止旧延迟触发续跑。延迟期间按 Esc 取消，不消耗尝试次数。通知启用时，每次续跑显示一次包含次数和延迟的警告。

使用以下固定续跑文本，不携带提供方错误正文、命令或工具输出：

```text
The previous turn was interrupted by an upstream transport error, so its work may be incomplete. Check what already exists and what side effects already happened, then continue the task from there. Do not redo work that is already done.
```

这是新续跑轮次，不是逐字节重发失败请求。它重新发送对话上下文并消耗提供方配额。已完成副作用保留且可能重复；此前未执行的调用可能执行。OMP 继续负责历史、调度和审批。历史保留原错误，续跑使用宿主隐藏上下文，不新增用户请求。

### 压缩期限

期限调整是默认关闭的进程级实验。远端自动压缩、手动压缩前或宿主报告正在压缩时开启窗口。窗口期间，有限的 `AbortSignal.timeout(ms)` 请求满足 `floor <= ms < timeout` 时获得配置 timeout。其他输入保持原生行为，包括非法输入的原生错误。窗口外全部输入保持原生行为。

第一个未中止的压缩取消信号归属当前操作。已经中止的信号关闭窗口；后续取消只关闭自己所属窗口，不能关闭之后的窗口。相同信号的重复通知，包括串行回退方法，沿用同一窗口，不延长 guard 期限，不重复通知和资源。不同的活动信号、重叠操作、另一会话的窗口或无法识别的事件顺序停止本进程实验并报告原因，第二个活动操作报告 `overlapping-round`。

压缩结束、压缩提交、会话切换、关闭、取消或 guard 到期中最早发生者关闭窗口。guard 从最初开窗事件开始计时。通知开启时，每个窗口只在首次延长期限时报告。

一个激活拥有进程级实验。后续激活的包版本与有效设置相同，则保留实验但不接管所有权、不开启窗口，并报告 `incompatible` 和 `patch-owned-elsewhere`。原所有者开窗期间，它仍共享进程级影响。不同版本或设置快照停止可识别的现有实验。停用或设置非法的激活也停止实验，不启用任何模块；其自身开关状态与 `/qol` 展示的进程实际状态分别表达。

所有者结束会话时停止实验，`owner-stopped` 成为本进程终态。必须重启 OMP 才能重新激活。会话切换只关窗，不结束激活。拒绝与可识别的旧压缩补丁共存，拒绝未知所有权、已被覆盖的自有调整、缺少必要宿主能力或已经停止过实验的进程。事件注册失败报告 `registration-error`，不留下活动实验。只释放仍由本组件拥有的资源，不覆盖其他扩展安装的替代项。

接受以下代价和限制：

- 窗口是时段，不是隔离的请求或项目。进程内全部匹配 timeout 都被延长，包括无关调用者和其他会话。
- 只能延长新建期限。关闭窗口不能缩短已创建的信号。期限限制单个信号，不限制全部重试和回退总时间。
- 启用实验会放弃宿主投机压缩。拦截生效时，不启动投机压缩，不将阈值延后给已有投机，也不消费投机结果。原本后台准备的压缩可能使前台等待。
- 原生压缩使用 300000 毫秒。floor 高于该值会使压缩请求本身不再匹配；`/qol` 明确说明。
- 进程级调整不写持久配置或会话状态。关闭并重启后恢复原生行为。

### 原生历史重放

启用时，恢复会话后的首个 `openai-responses` 请求使用已存储的提供方原生历史，包括可重放的思考签名，与宿主已预热会话相同。不重建、过滤或清洗历史，不改变会话文件。没有原生条目的会话没有内容可重放。`openai-codex-responses`、Anthropic、completions 等其他协议保持不变。

影响覆盖整个进程。另一个启用激活共享调整及改写次数，不创建第二份。原始激活结束后可以继续生效。关闭开关释放可识别的自有调整；设置被拒时以 `runtime-conflict` 停止，不启用默认值。未知所有权报告 `registry-unrecognized`，外来替换报告 `patch-overwritten`，无法激活报告 `install-failed`。拒绝不改变无关状态，释放不能覆盖他方替换。`/qol` 显示实时进程状态，不沿用过时的激活结论。

重放假定端点接受存储的原生条目。端点拒绝时，首请求可能失败，而原生重建路径本可成功。可复用提示上下文的量不同，不保证缓存命中或费用收益。调整不改变其他提供方协议，也不承诺覆盖宿主在可识别的提供方状态创建路径之外重建的历史。

### 任务参数

只为 schema 暴露 `sourceSession` 的内建 `task` 在宿主校验前执行清理。工具缺失报告 `unavailable`，被遮蔽报告 `incompatible`。schema 缺少该字段时报告 `unavailable` 和 `task-tool-without-seance-fields`，保留普通 `model` 选择器及投机启动。

扁平调用视为一个条目，`tasks` 数组视为批次。对 `agent` 为字符串、trim 后非空且不等于 `seance` 的对象，只删除该对象自身的 `sourceSession` 与 `model`，不论其值为何。保留 Agent 缺失、空、仅空白、非字符串及 `seance` 的条目，保留非对象条目、批次级字段和其他所有参数。不推断默认 Agent。一次改写调用计数增加一次，多项改写也只计一次；无变化不计数。

宿主显示、执行并持久化当前 assistant 的修订后参数，因此后续请求和会话文件会看到清理后的调用。不重写更早历史，不新增会话条目。保留原生 task schema、描述、审批、派发、后台生命周期和结果渲染。调用因其他原因仍无效时仍失败。多个扩展修改输入时，以宿主采用的最后一个修订为准。

接受的代价是在清理注册期间禁用任务投机启动和实验性读取投机，包括未改动的调用。不修改宿主设置本身。关闭模块后，下次激活恢复原生行为。缺少 `sourceSession` 的 schema 不承担此代价。宿主改变字段含义或范围时需要重新评估，不能猜测并扩大清理范围。

### 复制回复

在交互宿主读取扩展快捷键前绑定 `alt+shift+a`。每个扩展绑定拥有自身注册；会话 journal 切换保留已有绑定。在 pending、disabled 或 invalid 状态中，该键在绑定生命周期内仍被占用，但处理器不动作。与其他扩展的按键冲突由宿主裁决，本模块不处理。

启用且空闲时，选择当前分支最后一条 assistant 消息，跳过没有内容的 aborted 消息。把该消息的 `text` 块无分隔符拼接并去掉首尾空白。结果非空时通过宿主剪贴板助手复制。最后一条消息只有思考、工具调用或其他非文本时不复制，不回退到更早回复。不得写空字符串或复制非文本块。

忙碌时提示并保留剪贴板。没有可复制回复时提示且不写入。宿主助手通过 OSC 52 和原生剪贴板工具尽力写入，并吞掉写失败。助手正常返回后报告成功，即使底层写入实际失败。复制抛错时捕获并报告一次，不重试、不回退到文件，也不在通知中显示复制正文。复制不新增会话条目，不启动请求。

## 不变量

单项配置或可用性失败不影响其他有效调整。遇到无法识别的必要宿主结构时保留原生行为，不猜测。进程级影响遵守上述所有权和退出规则。键名、默认值、范围、未知键拒绝及无关设置值，在声明和两种语言用户文档中保持一致。

## 宿主下限

最低受维护 OMP 版本为 `18.5.0`，无维护上限。这不是安装或运行门禁，也不证明每个后续版本都能工作。较早宿主可能运行，但不在维护范围。宿主 peer 不限版本；必要宿主能力决定模块可用性。不保留只为维护下限之前宿主服务的路径。

## 验收标准

- 覆盖全部设置默认值、类型及范围错误、模块局部拒绝、整个对象拒绝、已退出键、重启语义，以及如实且只读的 `/qol` 输出。
- 等待覆盖显式和默认期限、全运行续等条件、全部终止结果、调用者取消、原生结果竞态、无关错误和拒绝替换未知入口。等待期限结束后后台工作继续。
- 在受维护的真实 OMP CLI 主会话中，默认恢复设置在符合条件的上游流错误后、不经用户消息自动续跑。原生重试或状态显示启用不能代替该证据。相同故障下关闭恢复不产生 QoL 续跑。真实 TUI 显示尝试次数和延迟，取消能阻止续跑。
- 恢复行为检查覆盖所报错误的真实宿主字段、两种模式、有标记和无标记的无状态错误、排除优先级、独立上限、退避、跨运行失败链、重复事件、失效延迟、开关、通知、原始错误不变及固定上下文。新真实会话重现精确报错措辞不是开发前提。
- 压缩检查覆盖区间边界、原生错误不变、同信号回退、取消、guard 到期、重叠操作、匹配和冲突激活、所有者退出、外来所有权、默认关闭及进程级影响。重放检查覆盖符合条件的恢复历史、不受影响协议、共享、释放及真实计数。
- 真实远端压缩超过原生期限后仍成功完成，随后仍能正常发起模型请求。宿主升级须重新验证该行为，修改维护声明不能代替该证据。
- 参数清理覆盖扁平和批次调用、seance 保留、全部排除的 Agent 形态、目标字段缺失、异常 task 形态、每次改写只计一次、内建及 schema 守卫、仅 model 的 schema、缺失或被遮蔽工具和开关。持久化的当前参数反映结果。
- 复制检查覆盖最后消息选择、拼接与去空白、空 aborted 消息、非文本排除、不回退、停用及忙碌状态、无文本及剪贴板错误、按键及时可用和 `/qol` 的实际键位。
- 各项真实 CLI 或 TUI 证据保存在对应验证资料，区分源码检查、自动检查和真实运行观察。未运行场景，包括精确报错复现、真实键位投递和剪贴板写入，标为未验证，不推断通过。
