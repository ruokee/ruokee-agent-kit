# tk 分发

## 目标

在 Linux 中离线安装、更新、切换语言和干净卸载普通 CLI Skill，目标为已知 Harness 根目录或用户指定根目录。安装内容不依赖源码检出，只更新检出不会更新已安装运行时或分发。

## 非目标

组件生命周期命令不安装、升级或卸载运行时本身，不安装第二个运行时、包装器、并行运行时版本或私有可执行文件。不使用网络来源，不接受本地 archive，也不依赖安装历史数据库。

## 公共面

### 运行时

固定公开运行时为 `$HOME/.local/bin/tk`，必须是至少带一个 Unix 执行位的普通文件。实际启动失败时保留操作系统错误。

### 选择

分发恰好包含两个普通 Skill：英文 `tk-cli` 和中文 `tk-cli-zh`，默认英文。每项包含完整参考资料，源码和安装后的全部文件引用都在自身内部解析，不含其他组件、产品源码、任务材料、审查记录或运行时可执行文件。相同分发输入产生相同的所选路径、字节、权限和分发内容。

分发格式 `5` 用语言和 Skill 标识选择，不含 Harness 身份。它声明运行时版本、来源修订、兼容范围 `>=0.1,<0.2`、允许的载荷路径、文件类型、Unix 权限和内容摘要。写入前的兼容及完整性检查使用这些事实。

install 必须且只能选择 `--harness codex|claude|pi|omp` 或 `--skill-root <directory>`，可选 `--language en|zh`。相对根按进程 cwd 解析，组件操作拒绝全局 `--cwd`。自定义根结果报告绝对 `skill_root`。

Harness 根目录映射为：

| Harness | Skill 根目录 |
| --- | --- |
| Codex | `$CODEX_HOME/skills`，默认 `~/.codex/skills` |
| Claude Code | `~/.claude/skills` |
| Pi | `~/.pi/agent/skills` |
| OMP | `~/.omp/agent/skills` |

两种目标只管理直接子项 `tk-cli` 和 `tk-cli-zh`。安装可以创建缺失的根目录和父目录。操作保留根目录及其他全部子项，不检查 Harness 配置或无关子项，不要求 Harness 可执行文件。

### 安装

安装只使用当前可执行文件携带的所选分发内容。预检和 dry-run 检查固定运行时、所选内容的格式与兼容性、完整性、可读受管目标、计划修改，以及不存在其他活动多目标操作。不支持的格式、不兼容运行时、错误选择、无效路径、不支持的文件类型或权限、重复项、缺失或额外内容及损坏内容都在持久写入前失败。预检不检查任务数据、WAL、项目配置、Git 状态或安装历史。

安装先写入完整所选 Skill，再从同一根目录删除另一种语言。

安装收敛到完整所选内容，替换所选目标内的偏差及额外内容。选择和受管目标集合相同时返回 `no_change`，否则为 `installed` 或 `updated`。有变更的 dry-run 返回 `would_install`，不写入内容。结果恰含 `harness` 或绝对 `skill_root` 之一，以及最终 `language`、`skill` 和计划或实际变更。

### 卸载

uninstall 必须且只能选择一个 Harness 或 Skill 根，不接受语言选择，返回 `would_uninstall`、`uninstalled` 或 `no_change`。结果恰含一个目标字段及计划或实际变更，两个身份都会删除，因此省略 `language` 和 `skill`。

卸载完整删除两个直接 CLI Skill 目标，包括修改和额外内容。内容摘要不用于保留残片。根目录、其他全部子项、用户配置、邻近路径及后续无关修改保持不变。不读取或修改 Harness 配置。

## 不变量

首次持久修改前完成全部领域预检。提交前复核计划目标。多目标操作按确定顺序提交，普通 I/O 失败或提交点之间取消时停止，报告真实 `completed` 和 `uncompleted` 项。部分完成是失败，不是支持的部分安装模式。不回滚、不创建续做 token，也不在 producer 退出后继续。

GC 只能删除归属明确的遗留 tk 临时内容，不改变规范 Skill 目标、其根目录或用户配置，不完成安装或卸载。

## 宿主下限

CLI Skill 不携带宿主进程代码，没有宿主维护下限。运行时和分发兼容要求保持独立。

## 验收标准

- 两种语言在各已知 Harness 根目录作为普通 Skill 放置和发现。Harness 场景观察真实发现及卸载后状态，不从安装文件推断。OMP 还通过 CLI 执行任务命令。
- 两种目标支持语言切换、dry-run、精确收敛、无变化及卸载，保留无关内容和配置。自定义根支持相对与绝对路径及缺失父目录创建。
- 生命周期不需要 Harness 可执行文件或配置访问。运行时缺失、非普通文件或无执行位均在写入前失败。
- 干净卸载删除两个自有目标内的修改及额外内容，保留根目录和无关项。
- 损坏或不匹配的分发内容在写入前失败。重复相同安装返回无变化，漂移恢复为完整选择。全部部分失败和 GC 效果保持准确可观察。
