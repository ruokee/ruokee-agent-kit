# Agent Note guidelines

Read [the Agent Note rules](./README.md) before adding or changing files in this directory.

- Search active notes before creating one. Update the current owner or record explicit supersession instead of duplicating a decision.
- Add and maintain the English `.md` file and Chinese `.zh.md` counterpart together.
- Keep both files in the same lifecycle directory and give them the same date and slug.
- Keep `Decision owner` and `Draft writer` identical across the pair. Record the concrete original Agent in `Draft writer` when known, and do not replace it with later editors.
- Follow the lifecycle-specific required sections. Use descriptive level-three headings when a required section needs internal structure; never replace the required level-two headings.
- Record a later material refinement to an implemented decision in a final `## Changes` / `## 变更` section, using a dated level-three heading for each refinement.
- The maintainer owns lifecycle transitions. Do not move a note between lifecycle directories without explicit approval.
- Keep `implemented` notes current with factual path, name, and verification changes, but never rewrite one into a different decision.
- Treat `archived` notes as frozen history. Do not edit them or cite them as current authority.
