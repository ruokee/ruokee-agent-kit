# ADR glossary

English | [中文](./glossary.zh.md)

Shared terms follow the [repository dictionary](../../docs/dictionary/README.md). This glossary keeps the ADR-local meanings.

## ADR

Corresponding Chinese term: `ADR`. A repository architecture decision record. An ADR is either a proposal or a decision.

See also [ADR in the repository dictionary](../../docs/dictionary/adr.md).

## proposal

Corresponding Chinese term: `提案`. An ADR that describes a change for review before implementation and before any resulting decisions are created or reversed.

See also [proposal in the repository dictionary](../../docs/dictionary/adr.md#proposal).

## decision

Corresponding Chinese term: `决定`. An ADR recording a complete current choice, rationale, considered alternatives, necessary boundaries and contracts, and consequences. Its first proposal date and canonical topic identify the current record and all its archived versions.

See also [decision in the repository dictionary](../../docs/dictionary/adr.md#decision).

## Update decision

Corresponding Chinese term: `更新决定`. Add non-conflicting content to a current decision under `Changes` without archiving it; a conflicting choice requires a reversal instead.

See also [update decision in the repository dictionary](../../docs/dictionary/adr.md#update-decision).

## Reverse decision

Corresponding Chinese term: `反转决定`. Create a complete successor from the old decision's still-effective rules and an accepted proposal naming the conflict. The replaced version is archived, and the canonical path holds the successor.

See also [reverse decision in the repository dictionary](../../docs/dictionary/adr.md#reverse-decision).
