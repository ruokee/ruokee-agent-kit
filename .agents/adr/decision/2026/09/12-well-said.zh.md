## 动机

使用前提供完整的双语写作指导，由 Skill 负责内部文件组织。

前驱将完整加载绑定到单个指令文件。行为要求是完整指导，固定文件数使内部整理成为仓库决定。解除形态约束不允许选择性加载日常写作规则。

来源署名归仓库 README，许可和来源事实归本决定。指令树内的法律通知可能被读成能力规则。Ruokee 对 well-said 的作者归属与 Lauren Tan 对复用 unslop 材料的作者归属保持区分。

## 决定

### 能力范围

well-said 保持独立编写、由模型调用。适用说明为"输出任何内容时使用"，包括回复、文档、代码和配置注释、Agent 交流。继续支持显式调用。

每种自包含语言组件提供完整的写作流程、文风模式、防御性表述、可见写作会话残留、文章写作和作者声音指导。两种语言保留含义及作者真实观察与判断，不依赖其他 Skill 或仓库支持文件。

防御性表述可能表示工作未完成，也可能只是写作问题。覆盖证明姿态、认知边界与未执行工作的交代，包含中英文代表表达、危害和处理方式。表达用于判断，不构成禁词表。

区分措辞问题和工作缺失。只是措辞过度谨慎时，直接陈述有依据的结论；工作缺失或错误时，在授权内补做或返工。工作正确时，按读者需要组织有用段落，删除空洞内容。保留事实、风险、未知、权限、必要理由及必需状态报告。

重写从原始需求和来源材料出发。旧 Skill 是辅助依据，不是验收清单；仅有章节覆盖差异不能证明缺陷。

### 组件布局

遵循普通 Skill 语言分发合同。每种语言以 `SKILL.md` 为入口，在 frontmatter 的 `metadata.version` 声明版本；组件负责内部指导组织，不固定文件数。对应语言的文件集合与行为保持等价。不论如何组织，日常写作均由完整指导支持。

指令正文不重复来源署名、许可文本或版本。仓库 README 署名来源 Skill 与作者，本决定记录来源与许可。首次正式版本为 `1.0.0`，后续遵循仓库版本政策。普通 Skill 不增加包 manifest、检测器、plugin 或运行时依赖。

[第一方能力决定](../08/20-first-party-capabilities.zh.md)区分能力归属和来源作者。文风部分保留大部分来源措辞、示例与有效组织，并作必要衔接和补充。保留材料来自 [Cursor plugins / pstack](https://github.com/cursor/plugins/blob/99559f2f52047978602ef365589275831e76af07/pstack/skills/unslop/SKILL.md)，版本 `99559f2f52047978602ef365589275831e76af07`，采用 [pstack MIT 许可](https://github.com/cursor/plugins/blob/99559f2f52047978602ef365589275831e76af07/pstack/LICENSE)，版权人为 Lauren Tan，年份为 2026。进一步分发复用材料前核实来源、权限、署名与通知。

### 编辑权限

指导适用于自然语言，包括代码和配置注释。引文、命令、标识符、原始日志、录制输出及其他字面材料在用途或请求要求时逐字保留。遵循所需文件、文本和结构；没有编辑许可的审阅保持只读。

unslop 的明确禁令保持强制性。[Skill 入口](../../../../../variants/zh/skills/well-said/SKILL.md)提供写作规则与示例。授权内的结构调整可重排段落、归并重复和重写开头结尾。大范围改动可询问整篇重写，已有许可足够，不设置任意比例门槛。保留固定结构。

按原信息和请求检查结果。不把未测试写成不支持、义务写成已完成行为、假设设计写成现有能力。保留具体未知，调查实质矛盾，不靠润色掩盖。

### 加载

应用前取得完整写作指导。入口描述、摘要和截断片段都不够，缺失内容须补齐。完整正文仍在上下文时复用，不逐次回复重读；上下文丢失后恢复。内部文件组织不能把必要指导变成可选，也不能等写作症状出现后才加载。

综合应用相关规则。纠正、撤销和替换须检查当前要求与会话残留，润色关注文风，反复自证须检查证明姿态。这些信号用于在完整指导中分配注意力，不用于选择性取得必要规则。普通输出遵循全部适用规则，清晰文字可保持不变。

加载失败时使用已有规则与保护边界，必要时说明受影响限制，不宣称已应用缺失内容。分别验证发现、完整加载和遵循，完整加载本身不证明写作质量。验证写作行为时使用新输入和回归检查。

### Agent 交流

自然语言委派、交接与审查反馈服务于接收方和后续读者。传递任务、材料、权限、范围、相关实际状态和验收。短消息只需包含影响接收方行动的内容。

省去重试、等待、调度和上下文整理叙述，除非它们影响接收方行动。保留阻塞、权限缺失、不确定或部分完成的写入、未满足依赖及防止重复副作用的信息。不把未完成或未知状态说成完成。

## 考虑过的替代方案

将全部指导固定为一个文件。这简化读取，但也让无害整理改变公共合同。不固定内部形态，仍要求完整加载。

只加载短核心及按信号选择的专项指南。低频材料可能节省上下文，但增加选择和读取失败路径。必要写作指导仍须在使用前完整取得。

## 结果

内部组织可调整，不削弱写作或加载行为。完整加载可能让与当前回复无关的细节占用上下文，应测量内容与加载行为，保持导航清晰。

过度清理可能丢失限定、迁移义务、证据、历史或作者声音，产生流畅但误导的文字。保护规则及保留与修改的配对案例约束所有指导，检查同时覆盖漏清理和有害修改。
