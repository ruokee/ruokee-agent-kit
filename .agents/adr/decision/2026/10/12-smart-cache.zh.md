# Smart context

Decision owner: Ruokee
Decision writer: OMP
Reverses: [smart-cache](../../../archived/2026/10/12-r1-smart-cache.zh.md)

[English](./12-smart-cache.md) | 中文

## 动机

在自包含扩展 `@ruokee/omp-smart-context` 中维护既有上下文能力。

这些能力的安装、原生设置和维护应当集中，状态归属和失败边界则各不相同。包级合同需要保留这些边界，不能把当前交付的能力清单变成永久架构约束。

## 决定

### 扩展自包含

在 `projects/omp-smart-context` 维护 `@ruokee/omp-smart-context`，使用一个原生 `omp.extensions` 入口、组件内依赖与检查，以及中英文文档。遵循[第一方边界](../08/20-first-party-capabilities.zh.md)与[自包含组件合同](../08/24-component-self-containment.zh.md)。只保留第一方能力，不从其他组件或本地原型导入运行时代码、设置读取器或文档。

### 能力归属

每项能力在自己的决定中持有行为、原生开关、默认值、运行状态、原因、适用的计数及验收。[README](../../../../../projects/omp-smart-context/README.zh.md) 和[组件 Spec](../../../../spec/omp-smart-context.zh.md) 拥有已交付能力清单与详细参考。未改变共同不变量的能力增删不反转包级决定。不交付占位设置、模式或接口，不引入通用模块框架。

共享协调器只属于[请求对齐](./22-request-alignment.zh.md)。journal、用量记账及模型规则状态各自持有。共同打包不合并协议规则、载荷形状、原因码或收益证据。模块局部失败或接口不可用不影响其他有效能力。

### 原生配置

OMP 管理用户值、项目覆盖及解析。从新包原生设置读取并校验一份有效激活快照。修改需要重启 OMP，创建或导航会话不刷新既有快照，重复激活不重复登记。没有包级总开关，每项能力保留自己的默认值。

未知键、非对象设置根或设置读取失败拒绝整个组件配置。模块键非法只停用该模块。诊断记录固定规则与原因，不输出设置值、正文、opaque、凭据、原始端点、私人路径或动态私密键。

### 状态

`/smart-context` 是包的只读状态命令，不启动模型 turn，分别报告各项已交付能力的状态、原因及适用的有界计数。能力自己的命令继续遵循各自合同。

组件双语文档拥有详细设置与命令、适用性、副作用、原生关闭表现、固定源码基线、实际运行版本及原生替换条件。源码检查、受控集成、真实 CLI 覆盖、客户端对齐、原生采用和 Provider 测量分别标注。

### 宿主维护

遵循[共同 OMP 维护下限](../09/28-host-maintenance.zh.md)，当前为 `18.5.0`。组件 README 双语页拥有下限声明，不设上限或版本白名单。宿主开发依赖锁定共同下限，host peers 不设限，不增加安装或激活版本门槛。面向 OMP 的组件下限只通过共同维护决定变更。

### 验收

使用仓库检查，以及实际扩展与锁定宿主库的本地受控运行。保留各能力正例、拒绝行为和独立开关，并验证组合行为。真实模型调用、缓存收益测量和完整 CLI/TUI 矩阵不作为集成门槛。Provider 收益声明仍需真实可比测量。历史证据保留原候选、条件与限制。

### 切换

删除旧包，不保留别名、适配层或跨组件依赖。用户在用户级与项目级显式迁移设置，保留有效启用意图和无关设置。运行时代码不回退读取旧命名空间，不修改用户配置或安装。按组件[迁移说明](../../../../../projects/omp-smart-context/docs/migration.zh.md)操作并重启相关进程，不热转移 owner 或参照，不接管外部包装。试验扩展的安装变更仍需授权。

后继保留包级决定的 canonical 身份，替代归档中的旧包名、`/smart-cache`、全部能力默认关闭及全部能力共用协调器条款。抽出的请求对齐决定保留该机制的义务，各能力决定保留自己的行为。

## 考虑过的替代方案

无

## 结果

共同发布和入口可能同时交付多项能力的回归。独立状态和失败边界限制相互影响，共享改动仍需组合受控验证。

试验扩展或旧扩展可能持有相同原生方法。共存可能使对齐停用，归属处理错误还可能重复改写。保守的冲突报告与重启切换保留归属边界，不自动修改安装。
