# 复制最后回复

Decision owner: Ruokee
Decision writer: OMP DeepSeek V4.1 Flash

[English](./18-copy-last-reply.md) | 中文

## 动机

`@ruokee/omp-qol` 增加一个固定快捷键，在交互式 OMP 会话中复制最后一条 assistant 回复的文本。

OMP 18.11.3 交互模式可用键盘动作复制输入框全文与当前输入行，另有鼠标 `Copy answer` 动作，并提供 `/copy` 命令让用户从会话中选择文本或代码。已安装的键盘动作表没有复制 assistant 回复的快捷键。只用键盘的用户若要复制整条最后回复，需要运行 `/copy` 并选择文本、在终端中选中，或重新输入。扩展 API 提供快捷键注册表，宿主也导出剪贴板助手，因此该能力可以作为扩展加入，不需要修改宿主。

## 决定

### 公共配置

组件在 [OMP QoL 决定](../09/20-omp-qol.zh.md)下新增一项调整 `copy`。其公开合同是一个原生 OMP 设置键 `copyEnabled`，boolean，默认 `true`，受组件总开关约束。它与其他设置在同一激活快照中读取。改动在下次启动 OMP 时生效。

快捷键固定为 `alt+shift+a`。模块不注册 `/copy` 命令，也没有可配置键位。已安装的键盘动作表没有绑定 `alt+shift+a`。快捷键注册表与剪贴板助手在 OMP 18.5.0 中已经可用。该键位属于公开合同。其他扩展不得在没有新决定的情况下占用它。

### 注册时机

模块在扩展工厂执行时注册快捷键，早于首次 `session_start`。OMP 先加载扩展工厂，再构造交互模式；交互模式在安装按键处理时读取快捷键注册表。在 `session_start` 中注册会晚于这次读取，无法成为该会话的键位绑定。因此处理器通过闭包读取激活快照；首次 `session_start` 之前 copy 模块为 `pending`，处理器不动作。

代价是扩展工厂为会话绑定时就占用键位。关闭 `copyEnabled` 或总开关，或设置被拒绝时，键位仍被占用，处理器直接返回，不复制。释放该键位需要卸载该扩展绑定或改变宿主。接受这一代价，是因为替代方案只能让快捷键在宿主可能尚未投递、且按键处理已经完成之后才出现。

OMP 每次为会话绑定扩展工厂时都会创建新的扩展实例，并在该实例的快捷键表上注册 `alt+shift+a`。处理器读取本次激活的快照与自身按键时的上下文。同一进程后续创建的会话获得独立的注册与处理器；一次交互会话内切换会话日志则沿用已有注册。

### 复制规则

处理器复制当前分支最后一条 assistant 消息，沿用宿主 `AgentSession.getLastAssistantText()` 的语义。它把该消息的 `text` 块无分隔符拼接、去除首尾空白，再通过 `@oh-my-pi/pi-coding-agent/utils/clipboard` 写入。内容为空的 aborted 消息会被跳过。最后一条 assistant 消息没有文本时，包括只带思考或工具调用的消息，不复制，也不回退到更早的回复。思考、工具调用、工具输出、图片及其他非文本块永远不进入复制文本。

agent 不空闲时，处理器提示并且不复制任何内容，因此流式期间按快捷键不会把上一条回复写进剪贴板。没有回复时，处理器提示没有可复制内容。宿主剪贴板助手是尽力而为并吞掉写入失败，因此真实写入失败不会被报告；复制函数抛出异常时会被捕获并给出一条错误提示，不重试。

模块只读取分支并写入剪贴板。它不新增会话条目、不发送请求，也不改动会话记录。

### 激活状态

模块开关关闭报告 `disabled` 与 `copy-disabled`，总开关关闭报告 `disabled` 与 `master-disabled`，`copyEnabled` 值无效只停用本模块。`/qol` 报告模块状态、实际开关值与固定快捷键。

## 考虑过的替代方案

无

## 结果

- **停用时仍占用键位。** 在该扩展绑定存续期间，模块关闭或设置被拒绝时，`alt+shift+a` 绑定到一个不动作的处理器。用户看不到复制结果，除 `/qol` 外也没有解释。
- **固定键位。** 想换组合键的用户无法修改；与其他扩展的冲突由宿主注册表处理，本模块不检测。
- **依赖剪贴板。** 写入使用宿主助手，它把 OSC 52 与原生回退都视为尽力而为并吞掉失败。真实写入失败不会被报告，模块也不提供回退文件或通知正文。复制函数抛出异常时会被捕获并报告一次。
