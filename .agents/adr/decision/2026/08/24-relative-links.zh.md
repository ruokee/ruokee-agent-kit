# 文件相对链接

Decision owner: Ruokee
Decision writer: OMP GPT-5.6 Sol
Reverses: [文件相对链接](../../../archived/2026/08/24-r1-relative-links.zh.md)

[English](./24-relative-links.md) | 中文

## 动机

文件链接相对于所在文档书写，复制到 GitHub Issue 或 PR 正文的模板除外。

相对链接支持 GitHub 按当前分支导航，也支持本地编辑器点击跳转。模板复制到 Issue 或 PR 正文后，源文件目录不再是链接的解析起点，因此文件链接需要不依赖正文所在页面的目标。前一决定统一禁止仓库文件使用 GitHub 绝对 URL，无法满足这一用途。

## 决定

供读者跳转的仓库文件引用使用 Markdown 链接，遵循仓库的[文件链接规则](../../../../rule/documentation.zh.md#文件链接)。

内容会复制到 GitHub Issue 或 PR 正文的模板，其文件链接使用指向仓库默认分支文件的完整 GitHub URL。该例外仅适用于这些模板正文中的文件链接，包括语言导航。

其他仓库文件链接的目标均相对于所在 Markdown 文档书写。当前目录或下级目录使用 `./`，向上返回时使用所需数量的 `../`。不使用前导 `/`、仓库根目录相对目标，也不为同一仓库的文件使用 GitHub 绝对 URL。

当链接文字标明文件时，从仓库根目录书写，不加前导 `/`。例如，`.agents/adr/decision/YYYY/MM/` 下的 ADR 这样链接 architect Skill：

```markdown
[skills/architect/SKILL.md](../../../../../skills/architect/SKILL.md)
```

显示文字从仓库根目录标明文件，相对于当前文档的链接目标则让同一个链接可以在 GitHub 和本地编辑器中跳转。

## 考虑过的替代方案

**正文模板继续使用相对链接。** 复制后的正文不再以模板目录为解析起点，链接可能落到 Issue 或 PR 路径，而非仓库文件。

**使用单份双语正文。** 这能避免跨文件语言导航，但会使每份默认正文更长，并改变分别提供完整语言版本的形式。

**全仓库使用 GitHub 绝对 URL。** 普通文档会失去按分支导航和本地文件跳转的能力，却没有解决额外需求。

**使用仓库根目录相对目标。** 不带前导 `/` 的目标会被 GitHub 从嵌套文档目录解析。添加前导 `/` 后，本地编辑器又可能从文件系统根目录解析。

## 结果

普通文档保留 GitHub 按分支解析的链接及本地文件导航。移动 Markdown 文档会改变相对链接的解析起点，必须在同一变更中更新受影响的链接。

正文模板始终链接到已发布的默认分支文件，不受正文所在页面影响。这些链接不跟随本地检出分支或 fork，新目标文件发布后才能通过链接打开。
