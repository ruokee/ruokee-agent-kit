## 动机

把任务行为集中在公开 CLI 后的唯一 Rust 运行时。

人、脚本和 Agent 需要相同的领域规则、持久化、输出、取消及资源限制。结构化预期失败必须保留操作系统错误和真实部分提交。

## 决定

### 运行时实现

`projects/tk/` 下一个 Cargo package 构建 `tk`，固定 Linux 路径为 `$HOME/.local/bin/tk`。接口、应用、领域、持久化和维护职责保持分离。每个命令使用短生命周期进程，重新解析工作目录、项目和任务状态，不使用后台进程、项目图缓存或常驻索引。

### CLI 合同

CLI 是唯一公开接口。[参考](../../../../../projects/tk/docs/design/cli-reference.zh.md)规定命令名称、参数、默认值、结果、稳定错误及退出状态。JSON 输入要求对象根，拒绝任意深度重复键。Agent 授权必须反映真实用户请求。

创建不接受正文输入：`tk create task` 拒绝 `--body`，子任务 item 把 `body` 作为未知字段拒绝。创建写入 `# <规范化名称>` 作为初始正文，后续正文编辑属于普通文件维护。

`tk rename` 保留精确任务引用，并修复符合条件的旧字符串名称或可识别生成式后缀。修复范围外仍执行原有校验。rename、`tk switch layout` 和 `tk migrate layout` 共用引用扫描、显式 `--update-references`、可重复 `--extend-scan`、持久 JSON 报告及摘要输出。默认保留引用原文。dry-run 只保存报告。无变化请求及有效项目中的规划失败也保存报告。

`task_layout` 为普通操作选择 monthly 或 daily，默认 monthly。布局 switch 转换当前根并最后写配置。布局 migrate 适配显式选中的导入规范目录，保留配置、元数据模式和 schema。共享布局和引用合同归[数据决定](./28-tk-data.zh.md)维护。

### 请求上下文

显式 `--cwd` 优先于运行时进程目录。完整绝对任务路径或材料路径可以独立定位所属项目，上下文不保存为任务状态。

actor 适用于 update、log 和 rename，默认为 `cli`，用于 WAL 归因，不表示身份、授权或任务分配。需要归因时，Agent 显式提供可用模型或 Harness 身份。

项目发现独立于 Git 策略。read、search 和诊断不受 Git 策略拒绝。受管项目写入在首次受管变化前立即运行共享 Git 检查。辅助扫描报告在该检查前保存。

### 资源边界

search 逐项处理候选，最多保留 100 个最佳项。check、关系图、schema 迁移及表示切换可以使用与任务数成比例的内存。布局预检合并所需任务图。共享引用扫描一起处理完整移动映射，每个待改文件保留一份原文快照。子进程 stdout 和 stderr 各限制为 1 MiB。

`tk read` 默认 `summary`。`minimal` 不读取正文或 WAL。`summary` 返回完整任务正文和不含条目正文的最近 WAL，默认 5 条、4000 字节。`detailed` 包含 WAL 正文，默认 50 条、16000 字节。显式预算为 0 至 50 条及 0 至 16000 字节。按视图投影后测量紧凑 JSON UTF-8 字节，从新到旧选择同时满足两项预算的完整条目，最后按时间顺序返回。省略不会增加截断字段、警告或诊断。完整历史通过每日文件提供，不增加分页或全历史读取模式。

`tk check` 独立流式检查每个普通每日 WAL 文件及全部条目，不设置固定总文件数、字节数或条目数上限。必要 I/O 失败指出路径，取消使检查不完整，有效 WAL 的规模本身不会产生 `wal_truncated`。

### 提交边界

单文件写入在原子替换前响应取消，已经开始的替换完成后再返回。多目标操作在提交点之间响应取消。首次受管写入前取消保留任务数据、引用和配置，已经保存的扫描报告继续可用。已有提交后，取消按 I/O 失败相同边界报告已完成和未完成项。

预期领域和环境失败使用公开统一结果。panic、进程被终止和输出损坏属于进程或内部故障，不伪造领域结果。部分提交包含已完成目标、未完成目标及原始错误，不自动回滚或产生续跑状态。元数据提交后的 WAL 追加失败作为警告返回。

rename 按移动、引用、元数据、WAL 提交。布局操作按目录移动、引用、最终 switch 配置提交，migrate 保留配置。受管写入前检查输入快照。报告作为不可变的执行前快照保存在项目保留目录 `.tk-tmp/reports`。摘要及错误携带实际完成情况、报告身份和配置状态。GC 保留项目报告，用户级清理语义保持原样。

### 合同归属

运行时、CLI 合同、任务 schema、组件格式和清理清单分别版本化。`tk --version --output json` 报告前四项。[CLI 参考](../../../../../projects/tk/docs/design/cli-reference.zh.md)完整规定必要行为、字段、默认值、失败语义、上限及兼容性。公开参考独立可用，[运行时设计](../../../../../projects/tk/docs/design/runtime.zh.md)解释实现，不补全缺失要求。

## 考虑过的替代方案

无

## 结果

短生命周期调用避免缓存失效和过期任务图，代价是进程启动和重复有界发现。运行时缺陷可能影响全部调用者。

CLI 名称、参数归属、JSON 字段、错误和版本是公开兼容边界，修改需要同步更新运行时、Skill、文档和验证。
