# 组件自包含

Decision owner: Ruokee
Decision writer: OMP DeepSeek V4.1 Flash
Reverses: [组件自包含](../../../archived/2026/08/24-r2-component-self-containment.zh.md)

[English](./24-component-self-containment.md) | 中文

## 动机

保持公开分发的组件文件自包含，同时允许声明运行时前置条件和使用项目内部维护 Skill。

解析到已安装组件之外的仓库文件引用，可能在只安装该组件时失效。按名称或公开接口提及工具或 Skill 不形成这种文件引用。组件有合理的运行时前置条件，读者需要看到明确声明。语言变体遵守相同边界，因为各个变体作为一个组件安装。

[前驱](../../../archived/2026/08/24-r2-component-self-containment.zh.md)将每个 Skill 都归为可分发组件。`.agents/skills/` 下的内部 Skill 维护本仓库，需要读取项目文档。按其项目内部用途分类，不削弱任何公开组件的文件边界。

## 决定

每个公开分发的 Skill、Extension、Plugin 和 Package 都是自包含组件。公开 Skill 根目录为 `skills/<name>/` 以及各个 `variants/<language>/skills/<name>/`。未来增加的可分发组件类别在各自根目录下遵守同一规则，每种语言变体独立自包含。

`.agents/skills/` 下的内部项目维护 Skill 属于仓库材料，不是可分发组件或安装源，可以引用所维护的项目文档。这一分类不豁免公开组件自包含要求，也不授权公开分发内部 Skill。

可分发组件内的仓库文件引用必须解析到该组件目录内。这包括 Markdown 链接、书面文件路径、导入、包依赖和运行时文件读取。组件不得链接、导入或读取另一个仓库组件的文件或包，也不得依赖组件目录之外的仓库支持文件，包括 `.agents/spec/`、`.agents/rule/`、`.agents/skills/` 和其他仓库级材料。像 `../code-quality/...`、`../../docs/...`、`skills/<name>/...`、仓库根相对路径和绝对路径这样的引用不会解析到组件内部，违反这一边界。

组件正文可以提及其他组件、工具或 Skill，把它声明为前置条件，并按名称或通过公开接口指示使用，包括加载 `skill://grill-me` 这样的 Skill。声明的前置条件不是文件或代码依赖。组件不必内置该前置条件、复制其实现或提供回退。前置条件必须显式声明，不能通过指向另一个组件文件的链接隐式形成。

自包含表示组件的文件集完整、能够独立安装、具有确定版本并可被单独阅读。它不表示组件没有运行时前置条件；组件的完整功能可以依赖已声明的前置条件。

需要另一个仓库组件文件的示例违反这一边界。按名称调用公开工具或 Skill、且不读取另一个组件文件的示例允许。组件仍可引用公开外部资料、外部 URL 和上游文档，讨论一般概念，提及与组件同名的外部库，前提是它不需要另一个仓库组件的文件。

组件目录之外的仓库级文档、ADR、manifest、安装器和集成代码，可以在描述或组装组件时引用它们。限制适用于从可分发组件内部发出的引用。

## 考虑过的替代方案

无

## 结果

每个可分发组件仍可脱离另一个仓库组件或源码布局独立安装、确定版本并被阅读，并能声明需要的工具或 Skill。缺少前置条件或版本不兼容可能导致失败或更弱的结果，仓库无法保证其版本兼容。组件仍不得链接另一个组件的实现。

相关组件可能重复少量指导。只保留适合该组件的内容，不镜像整份文档。内容在组件之间迁移时，在同一变更中迁移必要说明并删除旧的越界引用。审查将解析到组件目录之外的组件文件引用视为边界违规。

仓库级文档负责比较组件、说明组合方式和记录组件关系。内部维护 Skill 可以读取这些材料，不形成公开安装依赖。

## 变更

### 2026-09-28 组件维护说明

组件的维护声明及其宿主适配依据遵循[宿主内组件随宿主升级保持适配](../../../archived/2026/09/28-r1-host-maintenance.zh.md)，并留在组件目录内，因此组件不因这两类内容依赖仓库 ADR、其他组件或仓库级表格。这是把声明与依据纳入组件随附材料，不改变上文任何边界。
