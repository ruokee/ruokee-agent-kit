# 移除 ADR 术语表

Draft owner: Ruokee
Draft writer: OMP DeepSeek V4.1 Flash

[English](./17-remove-adr-glossary.md) | 中文

## 动机

移除 ADR 术语表，让仓库词典成为非组件部分唯一的术语来源。

[ADR 术语表](../../../glossary.zh.md)重复了拟议词典定义的五个术语：ADR、提案、决定、更新决定和反转决定。两份副本定义同一组仓库概念。由[仓库词典提案](./17-repository-dictionary.zh.md)提出的词典给出相同含义，并补充机制、示例、避免用词和归档版本。术语表没有独有词条。

保留两份副本会形成第二份权威。每次修改 ADR 术语都要同时更新两处，副本可能漂移。ADR 指南、仓库规格、仓库词典提案和两项当前决定当前要求或指向术语表，因此移除术语表也会改变这些绑定和文件。

## 提议

删除 `.agents/adr/glossary.md` 与 `.agents/adr/glossary.zh.md`。由[仓库词典提案](./17-repository-dictionary.zh.md)创建的词典 ADR 页及其中文页成为 ADR 术语的定义来源。

更新当前绑定：

- [ADR 指南](../../../README.zh.md)移除术语表链接、术语表阅读提示、根目录保留要求和术语表条目规则，改为指向词典的 ADR 页。
- 该变更引入的术语规则（`.agents/rule/terminology.md` 与 `.agents/rule/terminology.zh.md`）移除 ADR 局部术语留在 ADR 术语表的要求，并说明只有可分发组件的术语表保留本地副本，仓库其他部分使用词典。
- [仓库规格](../../../../spec/repository.zh.md)的中英文页面从公开表面和契约句子中移除术语表。
- [规格决定](../../../decision/2026/10/04-specifications.zh.md)与[仓库规则决定](../../../decision/2026/10/12-repository-rules.zh.md)的中英文页面移除“ADR 术语表保持不变”的陈述。这是事实维护，不需要反转。

已合入的[仓库词典提案](./17-repository-dictionary.zh.md)保留 ADR 术语表，并在验收标准中要求接入它。本提案取代这些术语表条款和验收标准；词典实现变更会移除已消费的提案，不接入也不更新 ADR 术语表。

反转 [ADR 机制决定](../../../decision/2026/08/22-adr-mechanism.zh.md)。其 `术语` 小节要求维护术语表，`路径` 小节列出术语表根目录位置，`维护` 小节提到配套术语表，`结果` 节限制术语表规模。这些条款与删除冲突，不能通过 `Changes` 追加。后继保留其余全部条款，包括 ADR 术语与根目录、决定身份、提案流程、记录格式、编写规则、决定生命周期、其余路径规则，以及不增加专用 ADR 工具的维护规则。被替代的决定移入下一修订号归档。

历史 ADR 归档保留历史选择、正文含义和术语表记录。ADR 规则允许并要求必要的关系与事实链接修复，包括让被替代决定的 `Reversed by` 跟随版本移动。其中对术语表的提及仍是历史记录，不是当前要求。

## 考虑过的替代方案

**保留术语表作为五条速查。** 它比词典页面短，ADR 作者也熟悉。但它重复词典，形成第二份权威，并需要同步更新。已否决。

**保留术语表并增加一致性检查。** 检查可以发现漂移，但不会消除重复权威；本工作不增加术语检查。已否决。

## 验收标准

- `.agents/adr/` 下不存在 `glossary*` 文件。
- ADR、提案、决定、更新决定和反转决定在词典索引与 ADR 页语言对中有定义。
- ADR 指南及其中文页不含术语表链接、术语表阅读提示、术语表维护要求或术语表条目规则；它们指向词典的 ADR 页。
- 术语规则及其中文页不再要求 ADR 局部术语留在单独术语表，并说明只有组件术语表保留本地副本。
- 仓库规格的中英文页面列出 ADR 指南与词典，不列出术语表。
- 已合入的仓库词典提案中的术语表保留条款和术语表验收标准已被取代；实现不接入也不更新 ADR 术语表。
- 当前 ADR 机制决定由后继替代，后继移除术语表条款并保留其他规则。被替代版本按实际归档日期和下一修订号归档。
- 当前文档不以链接或名称引用 ADR 术语表；讨论术语的当前引用指向词典的 ADR 页；历史归档保留历史选择与正文含义，只做必要的关系与事实链接修复。
- 在干净、已提交的候选上 `pnpm docs:lint` 与完整 `pnpm check` 通过。

## 风险

- ADR 作者失去五条速查，需要打开词典的 ADR 页。如果该页变得不完整，术语表的实用查询路径就消失了。
- 反转必须重建 ADR 机制决定而不丢失仍有效的规则。不完整的后继可能削弱身份、提案或生命周期规则。
- 在两种语言中更新指南、规则、规格和词典决定，可能留下过期引用或语言对不一致。中英文文件成对评审覆盖语义一致性；链接检查只覆盖解析。
