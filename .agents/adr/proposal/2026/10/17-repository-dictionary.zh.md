## 动机

为本仓库的开发工作建立共享词典。

术语定义分散在 `architect`、`code-quality`、`python-engineering`、`msgspec` 四份技能术语表和 ADR 术语表中。每份术语表只覆盖一个组件。跨组件的仓库概念、工作流概念和 AI 编程词汇没有共享定义。

部分术语被重复定义。`architect` 中的 `Recommendation` 是候选方向；审查技能中的 `Recommendation` 是针对发现项的最小充分行动。`architect` 中的 `ADR` 指通用的架构决定记录，ADR 术语表则指本仓库的机制。Agent 与维护者可能用同一个词表达不同含义，同一个概念也可能出现不同用词。

## 提议

在 `docs/dictionary/` 建立本仓库开发工作的共享词汇。

### 词条

索引位于 `docs/dictionary/README.md` 与 `docs/dictionary/README.zh.md`，按仓库与组件、文档与决策、工作流程、审查用语、AI 编程分区。每个词条给出规范英文用词、对应中文术语和一句定义。需要说明机制、示例或边界的词条另有一对互相链接的说明页。

首批覆盖仓库与工具链概念、审查用语和高频 AI 编程词汇。当前清单由词典索引维护。后续词条按需加入。

### 权威

词典是共享词的权威定义。组件术语表保留自包含副本，含义必须与词典一致；组件可以补充不与共享定义矛盾的适用范围说明。ADR 术语表保留 ADR 局部术语，并把共享词条指向词典。

`.agents/rule/terminology.md` 及其中文页规定：在仓库文档、规则、规格、决定、任务材料和围绕本仓库工作的讨论中，使用词典的规范用词和定义；已收录概念不引入同义表达；新词条由 Agent 向维护者提出，新增词条、变更规范用词或含义需要维护者确认。

### 仓库接入

- 根 `AGENTS.md` 链接词典和术语规则。
- 规则索引列出 `terminology.md`。
- 仓库规格在公开表面列出词典和术语规则。
- README 的文档层说明包含词典。
- ADR 术语表把共享词条指向词典，并保留 ADR 局部术语。
- 技能文件不引用词典或规则。

词典是仓库文档，不是可分发组件。`.omp/AGENTS.md` 通过 `@../AGENTS.md` 继承根文件，不重复引用。

### 来源

条目组织借鉴 Matt Pocock 的 [`dictionary-of-ai-coding`](https://github.com/mattpocock/dictionary-of-ai-coding)：简短描述、定义、可选的避免用词和示例。该仓库没有许可证文件，因此词典不复制其正文。词典索引和最终决定记录来源与无许可证状态。

## 考虑过的替代方案

**单文件 `docs/dictionary.md`。** 文件更少，但长篇解释和示例会挤在一页，并发编辑也容易冲突。已否决。

**可分发 Skill。** 可以为其他项目对齐词汇，但已确认的需求是本仓库开发；自包含的 Skill 也不能引用仓库级词典。已否决。

**把技能术语表并入词典。** 这会形成单一来源，但破坏组件自包含，也移除了已安装 Skill 自带的术语表。已否决。

**复制 Matt 的词条。** 覆盖快，但来源没有许可证。已否决。

**增加术语检查。** 约束强于已确认的需求，后者停在规范规则和评审。已否决。

## 验收标准

1. 索引为每个首批词条列出恰好一条记录，包含规范用词、另一种语言的对应术语和定义。同一概念没有两个竞争条目，同一条目不在索引中重复。
2. 需要说明页的词条有中英两份页面，互相链接、含义一致，并包含定义之外的机制、示例或边界说明之一。索引中的对应词条链接到该页面。
3. 术语规则与中文页等价并互相链接。根 `AGENTS.md`、规则索引、仓库规格、README 文档层说明和 ADR 术语表按上述方式接入。
4. 技能术语表和 ADR 术语表中的共享词不与词典矛盾。核对覆盖英文技能、中文变体和 ADR 术语表，受影响的副本同时更新。
5. 技能文件中不存在指向词典或术语规则的引用。
6. 词典索引记录 Matt 来源和无许可证状态，且不包含复制正文。
7. 实施后由决定记录约定机制，已消费的提案被移除。
8. 文档格式检查通过，完整仓库检查在干净、已提交的最终候选上通过。

## 风险

首批词条较多。只需要一句定义的词条可能写得过于表面，说明页也可能吸收过多词条。分配规则把说明页限制在需要机制、示例或边界说明的词条上。

中文规范术语可能与既有用法冲突。词典为每个概念确定一个用词，可能需要修改现有文档。

本次变更后，词典与组件术语表可能漂移。规范规则和评审控制这一点，不增加自动检查。

中英文页面可能在含义上分叉。两种文件同次修改，评审时成对阅读。
