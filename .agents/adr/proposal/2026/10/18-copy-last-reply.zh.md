# 复制最后回复

Draft owner: Ruokee
Draft writer: OMP DeepSeek V4.1 Flash

[English](./18-copy-last-reply.md) | 中文

## 动机

`@ruokee/omp-qol` 增加一个固定快捷键，在交互式 OMP 会话中复制最后一条 assistant 回复的文本。

OMP 18.11.3 交互模式可用键盘动作复制输入框全文与当前输入行，另有鼠标 `Copy answer` 动作。已安装的键盘动作表没有复制 assistant 回复的快捷键，也没有绑定 `alt+shift+a`。只用键盘的用户只能在终端里选中回复或重新输入。扩展 API 提供快捷键注册表，宿主在组件维护的 18.5.0 下限也导出剪贴板助手，因此该能力可以作为扩展加入，不需要修改宿主。

## 提议

### 公共配置

组件在 [OMP QoL 决定](../../../decision/2026/09/20-omp-qol.zh.md)下新增一项调整 `copy`。其公开合同是一个原生 OMP 设置键 `copyEnabled`，boolean，默认 `true`，受组件总开关约束。它与其他设置在同一激活快照中读取。改动在下次启动 OMP 时生效。

快捷键固定为 `alt+shift+a`。不提供 `/copy` 命令，也没有可配置键位。该键位属于公开合同。其他扩展不得在没有新决定的情况下占用它。

### 注册时机

模块在扩展工厂执行时注册快捷键，早于首次 `session_start`。OMP 先加载扩展工厂，再构造交互模式；交互模式在安装按键处理时读取快捷键注册表。在 `session_start` 中注册会晚于这次读取，无法成为该会话的键位绑定。

代价是扩展工厂为会话绑定时就占用键位。关闭 `copyEnabled` 或总开关，或设置被拒绝时，键位仍被占用，处理器直接返回，不复制。释放该键位需要卸载该扩展绑定或改变宿主。

### 复制规则

处理器复制当前分支最后一条 assistant 消息，沿用宿主 `AgentSession.getLastAssistantText()` 的语义。它把该消息的 `text` 块无分隔符拼接、去除首尾空白，再通过宿主剪贴板助手写入。内容为空的 aborted 消息会被跳过。最后一条 assistant 消息没有文本时，包括只带思考或工具调用的消息，不复制，也不回退到更早的回复。思考、工具调用、工具输出、图片及其他非文本块永远不进入复制文本。

agent 不空闲时，处理器提示并且不复制任何内容，因此流式期间按快捷键不会把上一条回复写进剪贴板。没有回复时，处理器提示没有可复制内容。宿主剪贴板助手是尽力而为并吞掉写入失败，因此真实写入失败不会被报告；复制函数抛出异常时会被捕获并给出一条错误提示，不重试。

模块只读取分支并写入剪贴板。它不新增会话条目、不发送请求，也不改动会话记录。

### 激活状态

模块开关关闭时状态为 `disabled`，原因为 `copy-disabled`。总开关关闭时状态为 `disabled`，原因为 `master-disabled`。`copyEnabled` 值无效只停用本模块。`/qol` 报告模块状态、实际开关值与固定快捷键。

## 考虑过的替代方案

- **在 `session_start` 中注册快捷键。** 可以避免在会话存在前占用键位，但宿主在首次 `session_start` 之前就构造交互模式及其按键处理。该注册对本来要服务的会话来说太晚。在解决注册时机时考虑。已否决。
- **注册 `/copy` 命令代替快捷键。** 命令可发现、可配置，但需要输入名称并回车。需求是在 TUI 中按键。在选择入口时考虑。已否决。
- **在工厂中读取 `copyEnabled`，关闭时不注册。** 模块关闭时可以释放键位，但工厂中的设置读取会使用 `process.cwd()`，在 `--cwd` 下可能与会话 `cwd` 不同，项目级覆盖可能从错误目录解析。激活快照是唯一按会话 cwd 读取的值。在解决注册时机与设置范围时考虑。已否决。
- **让键位可配置。** 工厂仍需要同样对 cwd 敏感的设置读取，改键也要重启。固定键位让公开合同和注册时机保持简单。在固定公开键位时考虑。已否决。
- **复制原始 assistant 消息，包括思考与工具调用。** 能保留模型产出的全部内容，但需求是回复文本，终端选区已经能暴露原始内容。在定义复制内容时考虑。已否决。
- **最后一条回复没有文本时回退到更早的回复。** 能让快捷键更常产出内容，但会复制用户刚刚没有看到的回复，也会掩盖空回复或只有工具调用的轮次。在定义复制规则时考虑。已否决。
- **用换行拼接所有文本块。** 能在多块消息中分隔段落，但宿主 `AgentSession.getLastAssistantText()` 直接拼接文本块，并在选中的消息没有文本时返回空；本模块沿用该方法。在匹配宿主文本提取时考虑。已否决。
- **通过操作系统命令写剪贴板。** 可以不依赖宿主助手，但会增加平台分支，并与宿主的 OSC 52 与原生回退不一致。宿主导出是受支持的接口。在选择剪贴板写入方式时考虑。已否决。
- **把功能留给现有宿主动作。** 已安装的键盘动作表没有复制回复的动作；鼠标 `Copy answer` 需要指针，无法满足键盘需求。在检查现有宿主行为时考虑。已否决。

## 验收标准

- 模块启用且 agent 空闲时，按 `alt+shift+a` 把最后一条 assistant 消息的 `text` 块写入剪贴板，块间无分隔符并去除首尾空白。
- 最后一条 assistant 消息没有文本时不复制，也不回退到更早的回复。思考、工具调用、工具输出、图片及其他非文本块不进入复制文本。
- agent 不空闲时，快捷键提示并且不复制任何内容。
- `copyEnabled` 关闭或总开关关闭时，快捷键不复制，`/qol` 报告 `disabled` 与对应原因。键位仍被占用。
- `copyEnabled` 值无效只停用 `copy` 模块。
- 不提供 `/copy` 命令，也没有可配置键位。
- 复制函数抛出异常时给出一条错误提示，不重试。
- 包 manifest 声明 `copyEnabled` 及其默认值与说明。组件文档、根 README 组件列表与 Spec 描述行为、固定键位及其占用规则、剪贴板限制。

## 风险

- **停用时仍占用键位。** 关闭模块或总开关后 `alt+shift+a` 仍绑定到一个不动作的处理器，用户得不到复制结果。
- **固定键位冲突。** 其他扩展可能注册同一个键；宿主选择一个注册，用户可能得不到本模块的复制结果。
- **复制范围窄。** 快捷键只复制最后一条 assistant 消息的文本。想复制更早的回复、工具结果、图片或思考的用户不会得到内容。
- **流式守卫。** 流式期间按快捷键不会复制；用户若忽略提示，可能粘贴剪贴板中的旧内容。
- **剪贴板失败被吞掉。** 宿主助手吞掉写入失败，用户可能以为复制成功，而剪贴板没有变化。
- **验证缺口。** 真实 OMP CLI 的键位投递与系统剪贴板写入尚未测试；平台相关失败只会在实际使用中暴露。
