## 动机

通过内部 `maintain-spec` Skill 维护双语当前目标规格。

规格为维护者和 Agent 提供一份当前说明，表达组件或仓库领域应该是什么、边界和可观察验收。当前决定及带日期变更解释理由，组件文档持有详细用户契约，这些职责不能相互替代。

[前驱](../../../archived/2026/10/04-r1-specifications.zh.md)将编写、维护和职责分工规则归给 Spec README。把这些规则交给 Skill，可以按需提供完整方法，README 则保留项目清单和补充，不重复完整指南。

## 决定

### 位置

规格位于 `.agents/spec/`，与 ADR 和规则并列。`projects/` 下每个组件都有规格，tk 作为整体覆盖。对外分发 Skill、仓库约定和宿主兼容也有规格。[Spec README](../../../../spec/README.zh.md) 持有清单和项目补充，增加或删除组件、增加需要规格的仓库领域时，同一变更更新清单。

[maintain-spec](../../../../skills/maintain-spec/SKILL.md) 是 `.agents/skills/` 下的英文内部项目 Skill。仓库规格覆盖它和内部 ADR 维护 Skill。公开 Skill 规格继续覆盖 `skills/` 与 `variants/zh/skills/`，内部维护不增加公开安装源或翻译分发包。

### 目标权威

规格说明当前目标，就地修改，不保留修订历史、审查记录、任务记录或会话信息。依据已确认需求、包含 `Changes` 的当前决定和所属组件文档编写。归档决定不是当前权威，当前规格不引用或复制归档决定。已有实现本身不批准目标。

规格不能与当前决定冲突。改变目标前识别冲突条款，并遵循 ADR 机制。不形成持久选择的变更不需要 ADR。决定可以链接规格，但链接不能代替决定自身契约。改变组件目标时，同步更新规格、组件和组件文档。

### 维护归属

Skill 持有[结构](../../../../skills/maintain-spec/SKILL.md#write-the-current-target)、[职责分工](../../../../skills/maintain-spec/SKILL.md#division-of-work)，以及新增、调整、移除、边界澄清的方法。适用章节保持目标、非目标、公共面、不变量、宿主下限、验收标准、相关 ADR 的顺序，不适用章节省略。详细命令、参数、设置、格式和维护声明留在所属页，规格链接它们并只补必要上下文。

项目补充持有同目录英文和中文配对、标题下紧接互链、同变更语义一致等要求。语言与 Git 政策是项目选择，不是 Skill 强加的统一要求。

Agent 入口与 Skill 描述在加载前说明适用工作。规格维护、审查或功能工作影响长期目标时，Agent 加载 Skill，读取有效决定及变更、提案、项目补充和必要组件来源，保留未受影响要求并核对文档结果。只读请求保持只读。

任务 Goal 可以提供已确认需求，但 Skill 不形成、访谈、修订、重命名或保存 Goal，不管理任务生命周期。已有 `spec.md` 任务文件仍属于任务材料。只有工作需要不同职责时才使用 `maintain-adr`。

### 引用方向

规格可链接组件文件、组件文档、ADR 和规则。可分发组件不链接、不写出 `.agents/spec/` 路径，也不在运行、构建或分发时依赖它。内部项目 Skill 可以读取所维护的项目文档，不放宽公开组件自包含要求。

规格仍是由 Markdown 检查处理的说明性文档，不为该层增加专用检查器或运行时读取方。维护 Skill 自身使用原生项目发现，其 Markdown 属于已知文档检查范围；未知文件和共享检查输入仍执行完整验证。

## 考虑过的替代方案

把每份规格放进其组件目录。这样规格靠近代码，但会分发用户不需要、又引用仓库来源的维护者材料。对外分发 Skill 和仓库约定也没有承载整体规格的单一组件目录。

完整维护规则留在 Spec README，Skill 只给步骤。这保留原归属，但方法被拆在操作流程与完整规则来源两处。所选归属需要一次性迁移有效条款和引用。

## 结果

维护者和 Agent 对每个对象都有一份当前目标、边界、不变量和验收说明，并能通过链接找到细节所属决定与文档。Skill 和项目补充各有明确职责。

过时规格、遗漏决定变更或导入历史规则，可能把实现引向错误目标或删除必需行为。当前决定约束冲突，目标变化同步相关文档。格式检查不能证明语义一致或 Skill 使用成功，实际维护会话必须显示适用加载、正确读取，以及按已确认要求正确维护文档。
