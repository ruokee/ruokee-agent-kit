# 文档

[English](./documentation.md)

本文规定公开 tk 文档的布局、语言配对、主题归属和维护规则。

## 公开页面

公开文档包含：

- 英文和中文用户指南；
- 英文和中文设计索引；
- system、data-model、runtime、tool-api、cli-reference、harnesses、installation、skill、validation、documentation 和 GLOSSARY 的英文中文对应页面；
- 仓库根 README 和中文 README 中的 tk 入口；
- 当前英文和中文 tk ADR。

评审记录、修订号、Task 路径和本地材料不进入公开页面。

## 主题归属

| 页面 | 负责内容 |
| --- | --- |
| guide | 运行时前提、安装、首次使用、常用工作流和 CLI 链接 |
| system | 产品范围、系统组成、Task 与 Harness 边界和不变量 |
| data-model | Task schema、表示、发现、WAL、写入、迁移、rename、清理和检查 |
| runtime | 分层、进程、上下文、失败边界、适配器和版本维度 |
| tool-api | 六个工具、请求、结果和稳定错误 |
| cli-reference | 完整命令树、参数、默认值、退出码和示例 |
| harnesses | 四个当前 Harness 组件、schema、适配器和组装 |
| installation | 内嵌组件、安装、更新、干净卸载和兼容性 |
| skill | Agent 触发、授权、Task 导航、WAL 和材料行为 |
| validation | 可观察验收合同 |
| documentation | 文档布局、语言和维护规则 |
| GLOSSARY | 项目特殊术语和固定译法 |

一个行为的参数表或算法只出现在主要归属页面。其他页面链接到它，不复制第二份合同。

## 当前状态写法

公开文档只描述正式发布后的当前命令和行为。

开发阶段曾经出现但从未正式发布的命令、参数、文件、兼容层和设计尝试不写入公开文档，也不专门列出“不再支持”。只有正式发布后的真实行为变化，才按用户迁移需要记录版本差异。

文档陈述最终状态，不叙述修改过程、审查争论或 Agent 工作记录。

## 英文和中文

每个 design 专题和 guide 在一级标题后提供指向另一语言的链接。链接使用仓库内相对路径。

英文和中文页面语义对应，但中文应按自然中文重写，不做逐句机械翻译。命令、字段、代码、日志和必须固定大小写的产品术语保持原文。

中文仓库索引和根 README 使用自然段落中的语言入口，不强制套用专题页面格式。

固定译法见[术语表](./GLOSSARY.zh.md)。

## ADR

ADR 使用 Harness 术语。安装相关 ADR 的英文和中文文件名、标题和链接都采用 Harness，不保留 host 命名别名。

ADR 提案位于 `proposal/` 或 `rejected/`，决定位于 `decision/` 或 `archived/`。ADR 文件不包含 `Status` 字段。维护者负责批准或拒绝提案，以及归档决定；设计、实现或验证完成不会自动改变生命周期状态。

英文和中文 ADR 文件对在同一变更中保持语义一致。

## 链接

仓库内 Markdown 链接使用相对于当前文档的路径：

- 当前目录或后代路径以 `./` 开头；
- 上级路径使用必要数量的 `../`；
- 仓库内文件不使用绝对路径或 GitHub 绝对 URL。

文件名作为链接文字时，从仓库根描述文件路径，不加前导 `/`。

## 写作

- 定义和要求使用直接句子。
- 数据保护、安全边界和明确拒绝规则可以使用否定表达。
- 删除没有新增信息的防御性否定，不设置机械数量指标。
- 使用 `human-readable` / `人类可读`、`managed` / `受管`、`scratchpad` / `临时记事区`、`clean cutover` / `直接切换` 和 `supported subcommands` / `支持的子命令` 等固定译法。
- 不把实现细节和普通技术词塞入全局术语表。

## 检查

文档依赖仓库现有 Markdown、链接、格式和拼写检查，并进行人工双语审查。不增加 tk 专用的双语结构检查器。

更新一个公开行为时，同一变更必须更新：

1. 负责该行为的设计页面；
2. 受影响的 guide、Skill 和 CLI 示例；
3. 对应中文页面；
4. 描述该合同的全部当前 ADR；
5. 验证文档中的对应验收项。

评审材料可以解释理由，但不能成为公开合同的唯一来源。
