# 设置

用户请求初始化或重新配置，或实际失败需要特定准备信息时，遵循已加载的[入口](./SKILL.md)。Setup 管理外部默认，不负责安装，不是普通使用前置，也不授权实现或交付。不为配置默认值而加载 Task、执行或检查细节。

## 确定位置

读取预期范围和适用外部指引，复用既有选择。编辑前明确获准位置，例如项目既有 `AGENTS.md` 或等效指令文件。初始化不授权无关全局或受保护写入，保留未知和无关内容。

按当前问答限制，只解决证据中缺失且重要的选择。不把默认值写入已安装 Skill、Task 结果、新配置数据库或自行发明的用户与项目覆盖层级。不需要占位 Task。

## 选择默认值

配置角色时读取[角色选择](./references/roles.md)。按请求独立记录自检者、Verify 和 Senior 的默认宿主、准确模型选择器或别名、支持的推理等级及适用工作位置。Worker 默认可以沿用项目 Agent 惯例。Senior 默认不启用该角色。

按请求分别记录准备材料与实现单元的自检上限。未配置时由执行者选择三至五次。上限限制次数，不要求做满。[自检规则](./references/self-check.md)负责计数、通过即停和耗尽后的处理，不把算法复制到外部设置，也不在 Setup 中启动检查。

按请求记录所选协作工具及项目特有约定。把协作工具的选择留给用户或项目；Tern、Herdr、tmux 是示例，不是偏好。[协作合同](./references/collaboration.md)负责会话使用、等待和结果恢复，不复制到设置。不为设定默认值启动角色、安装工具或探测环境。

## 记录项目惯例

按请求和许可记录选定的分支或 worktree 方式、候选保留、必需检查及共享编辑归属。采用项目安排，不强加通用布局。

定义项目 Ship 结果及其必需动作、检查、验收、受保护许可和允许清理。例如提交 PR 等待审查、运行本地应用供评估，或更新 Harness 安装进行获准试用。选择实际结果，不将示例合并为必做步骤。

流程说明不授予当前执行许可。定义 Ship 不关闭 Task，也不要求生产交付。缺少自定义定义不阻塞其他已明确操作。

## 应用设置

只编辑获准外部指引，保留其风格。保存所选值和项目特有选择，不复制通用流程，也不写入会话路由、临时授权、实时身份或待完成分派。替换适用默认，不追加冲突副本。

当前明确选择在用户改变前继续有效。默认更新不静默替换活动角色选择，相关时重读已变指引。在可恢复状态中保留配置范围、位置、有效选择、许可和下一步。

实际失败后记录错误，只获取当前许可内解决该前提所需的细节。能力不可用时直接报告，不削弱验收，也不声称配置能证明宿主或模型行为。

返回指引位置、有效默认及范围、已观察检查和实际阻塞。Setup 完成不启动实现、交付或 Task 关闭。
