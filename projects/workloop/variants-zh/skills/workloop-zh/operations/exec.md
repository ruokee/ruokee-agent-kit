# 执行

遵循已加载的[入口](../SKILL.md)，解析分派前读取[任务归属](../references/task.md)和[执行约束](../references/execution.md)。当前会话亲自实现并直接协调检查，不需要 Supervisor。遵循项目工作惯例。

## 解析单元

确定实际执行请求及所属 Task 后，读取其当前 tk 状态。若为 `planning`，在检查 Plan 是否就绪之前，通过 tk 公开接口启动，例如 CLI 的 `tk update <task_ref> --start`。不等待实施开始。该执行请求授权启动所属 Task，不授权改变其他 Task。

若已为 `open`，直接继续，不重复启动。`closed` Task 遵循 tk 单独的重开许可。恢复会话或启动失败时，通过 tk 核实实际状态后再实施，不手工修改托管元数据。

读取所属 Task 的目标、必需的 `plan.md`、链接单元细节、相关设计与决定、依赖、当前实现、验收及执行证据。单单元任务也需要独立 Plan。只有受缺失或尚不可执行规划影响的范围返回[澄清](./clarify.md)，不在实现中发明要求。父 Plan 中各项就绪程度不同时，按共享执行约束处理。

因缺失规划，或执行、核验、用户验收发现问题而返回 Clarify 时，Task 保持 `open`。工作流可以回到前面的阶段，tk 状态不退回 `planning`。

按执行约束处理所选范围、许可、连续推进和问答限制。需要角色时读取[角色选择](../references/roles.md)，接收分派或跨会话派工时读取[协作](../references/collaboration.md)。只有明确分配后才使用 Senior。

在可恢复状态中保留 Task、单元、依据和入口位置、候选、范围与授权、明确限制、自检次数与上限及下一步。实时路由和待完成分派按协作规则保存。

## 实现

复用项目惯例，完成所请求改动，保留无关工作和有效要求。只准备已授权实现与检查需要的本地环境和临时进程，不增加预检、假想功能、兼容层或无关兜底行为。

同步更新受影响调用者、合同和文档。实际运行改变的行为，执行必需检查，在不削弱验收的前提下修复范围内失败。记录条件和观察，不只记录退出状态。遵循项目候选提交规则，保留稳定候选供检查。

在既有执行记录中保存实质结果，通常为 `execution.md`：单元、分支或变更位置、依赖基线、候选、完成行为、输入、观察、命令及结果、覆盖、偏差和剩余限制。保留失败及修复的追溯关系。保留重建来源，不把已安装依赖当作证据。获准清理前停止所拥有的临时进程。

按执行约束使用已验证前序候选。缺失产品决定或必需能力阻塞依赖动作，不能据此把不完整替代品称为完成。

## 自检

实现及实际检查后读取[自检](../references/self-check.md)。提供本单元依据、冻结候选、证据和获准结果位置。结果保存到执行记录或其链接的自检记录，不写入独立 Verify 报告。遵循新上下文、累计计数、通过即停和上限规则。作者修复并重跑受影响检查。

## 取得独立 Verify

每个实现单元都需要独立 [Verify](./verify.md)，自检通过也不例外。按执行授权及角色、协作 Reference 选择并启动或复用合适的隔离核验者。提供 Task、当前单元、冻结候选位置和当前回复负责人。由核验者加载自己的操作，解析依据和报告，不在此复制核验方法。

按协作规则等待并核对最终结果。`changes required` 时范围内修复，实际运行受影响行为，更新证据，冻结新候选，向同一合适核验者请求复查。独立反馈不重置自检计数。`unable to determine` 时解决准确的缺失前提，不改贴结果标签。保留待完成请求，不重复分派。

连续完成获准修复及复查，不索取例行中间确认。明确请求限制和真实人工接入点仍然有效。

## 继续

当前独立核验通过后保存单元结果，在本次执行中开始下一项已授权且依赖就绪的单元。仅等待用户审阅或前序集成不要求停止。Worker 到分派边界停止并向负责人返回最终结果，由负责人继续总体 Plan。

剩余工作确实全部阻塞时，保存每项阻塞、已完成候选和准确缺失的事实、状态或许可，保留完整所选范围。该范围完成后一起提交候选供用户审阅。集成和 Ship 需要各自有效许可。

## 返回

保存执行记录，链接独立报告，不复制报告内容。逐单元简要返回 Task、单元、位置、基线、候选、完成行为、材料路径、已运行证据、覆盖、限制、自检次数与结果、独立结论及报告、用户审阅或提前批准状态、交付状态及实际剩余要求。

不从执行完成推定合并、安装、重启、发布或 Task 关闭。保留已验证未集成候选，供项目定义的交付使用。
