# 设置

完整读取[公共合同](./SKILL.md)。用户请求初始化、重新配置 workloop，或实际失败需要相关准备细节时使用本说明。初始化不是普通使用的前置条件，也不授权实现或交付。

## 解析设置

读取用户期望的范围及适用外部指引，复用已有选择，不重复提问。根据项目约定及用户写入许可，将长期默认保存在适用 `AGENTS.md` 一类指引。不写入安装的 Skill、Task 结果、新建 workloop 配置数据库或自行设计的用户级与项目级覆盖体系。

只澄清影响使用且证据无法回答的选择，遵循当前问答限制。编辑前明确准确位置；初始化 workloop 的请求不授权无关全局或受保护写入。保留其他指引，不覆盖未知内容。

## 选择角色

用户需要时，分别记录快速自检、Verify 及 Senior 的默认值，包括宿主、准确模型选择器或别名，以及宿主支持的思考强度。Worker 默认可沿用项目既有 Agent 约定。不向 workloop 分发指令写入具体模型或提供方。

有效选择按当前明确请求、同次执行继续有效选择、适用外部默认的顺序解析。发送给宿主时保留别名。选择不可用时报告实际错误，不静默替换。不从执行者推断 Verify。Senior 默认不分配角色，仍须明确启用。

## 设置检查上限

用户配置时，分别记录前期材料自检和实现单元快速检查的最多次数。没有配置时，执行者按任务情况在三至五轮中选择默认上限。明确最多四轮一类数值表示上限，不要求做满四轮。

首次检查通过即可结束。首次与复查共同计数，前期材料与各实现单元分别计数，修订或独立 Verify 反馈不重置。达到上限后停止追加，完成可处理修订，说明未解决和未复查工作。独立 Verify 没有自检次数上限。记录数值时保留这些含义。

## 选择协作方式

使用项目选择的终端协作方式。需要选择时推荐 Herdr，但不设为必需；tmux 或其他受支持方式同样有效。在外部指引记录所选工具及相关项目约定。

各方式都须支持正常会话启动、普通消息派工、角色隔离、适当会话复用、明确工作位置及回复路由、候选冻结、最终结果等待，以及失送后恢复已保存结果。具体命令遵循所选工具说明。`nowait` 只改变跨会话请求等待，原生自检仍须等待完成。

不为建立默认值就启动所有角色、安装工具或探测环境。实际工作需要时再使用所选方式，动作失败后处理具体错误，不将初始化变成通用预检清单。

## 记录项目约定

只在请求及许可内协助维护项目工作方式，可以包括分支及 worktree 约定、候选保存、检查和共享编辑归属。workloop 遵循外部规则，不统一规定开发布局。

将项目 Ship 定义为可观察结果，并写明必需动作、检查、验收条件、受保护许可及允许清理。例子包括提交 PR 供审查、运行本地应用供评估，或更新 Harness 安装并进行已授权试用。选择项目实际目标，不将例子合成必做步骤。

区分流程说明与执行许可。记录发布或安装流程不授予当前发布或安装许可。定义 Ship 不自动关闭 Task，也不要求生产交付。缺少自定义 Ship 不阻塞其他已明确操作。

## 应用变更

只编辑获准外部指引，沿用原有风格。说明记录了哪些选择及其位置，以及影响使用的未决设置。不把会话路由、临时授权、实时 Agent 身份或待完成分派写入长期默认。

重新配置时替换适用既有默认，不追加冲突副本。用户改变前保留当前明确选择；更新默认不静默替换活动执行中已选角色。相关时重读变化后的指引。

实际加载或工具动作失败后，记录错误，只获取最小相关细节，在许可内解决具体前置条件。不能提供的能力直接报告，不削弱验收，也不把配置变更说成宿主或模型行为已获验证。

返回变更指引位置、有效默认及范围、实际执行的检查和剩余阻塞。不因初始化完成就启动实现、交付或 Task 关闭。
