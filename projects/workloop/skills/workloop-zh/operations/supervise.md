# 监督

完整读取[公共合同](../SKILL.md)。通过独立 Worker 协调所解析的 Plan，不亲自实现其变更，也不将本会话用作其独立核验者。

## 解析计划

读取所属 Task 的目标、必需 `plan.md`、链接单元细节、依赖、已接受决定、已有候选、报告及项目规则。准备不完整时，将受影响工作返回[澄清](./clarify.md)，不交给依据不足的 Worker。

指定子集时限制调度范围，否则从所解析起点继续剩余 Plan。调度范围、各 Worker 分派、受保护许可及并行分别处理。监督入口不启用 Senior，也不授予集成许可。执行默认连续推进，禁止结构化问答工具。`confirm` 表示逐项确认，不取消必需检查，也不启用结构化问答。

按公共角色规则分别解析 Worker、自检、Verify 及明确分配的 Senior。实时身份、待完成分派、归属及资源位置保留在可恢复运行状态，不写入 Task 材料。

## 分派工作

选择依赖就绪且有完整结果的单元。Worker 通常同一时间只处理一个单元，可以在明确分派范围内串行完成多个。请求范围及项目允许时，独立单元可以交给不同 Worker 并行处理。不在共享编辑或未解决前置条件上制造并行。

向各 Worker 提供所属 Task、单元及 Plan 依据、实际工作位置、编辑边界、有效许可与限制、依赖候选及基线、必需检查、获准材料、预期结果、停止点及实时回复对象。存在明确分配的 Senior 时带上其咨询范围和路由。以明文传递禁止结构化问答，不只写 `noask`。

通过 workloop Execute 操作分派实现，让 Worker 实现、实际检查行为、完成自检及独立 Verify、保存证据并返回分派范围的最终结果。Worker 单元边界不取消负责人继续整个 Plan 的授权。不转授未获许可的动作，也不添加与用户有效范围冲突的停止条件。

通过所选协作方式正常启动会话并发送普通消息，遵循公共最终结果等待。显式 `nowait` 允许跨会话工作保持待完成，但不取消原生自检屏障。不读取工作中私有会话文件，不发未经请求的中途消息。咨询已分配 Senior 时，使用有边界的请求，注明具体决定及当前回复路由。

## 协调候选

共享文件或逻辑同时只有一个编辑所有者。任何审阅期间冻结候选。合适的隔离 Verify 和已分配 Senior 会话跨单元复用；核验者忙碌时，先完成或恢复当前分派再接下一项。协调独立工作，不将实现上下文变为核验上下文。

按项目本地提交及分支约定保留各已完成候选。已验证但未集成的前序候选可提供后续开发基线，等待用户审查或集成本身不阻塞该依赖。冻结前序候选，记录各单元身份和基线。前序变化时刷新后继及受影响检查，外部状态依赖仍需要真实前提。

## 处理结果

逐份核对最终结果的发送者、Task/单元、候选及基线、变更范围、实际检查、自检次数及结果、独立 Verify 结论及已保存报告、已知限制。读取报告，生命周期标签、实现完成声明或快速检查通过都不是独立核验。

需要范围内修订时，将具体发现交回负责 Worker，保留原检查计数，要求受影响检查及独立复查。复用已有合适核验者。无法判断时识别具体缺失证据或能力，在许可内解决。通信失败时恢复已保存结果，不重复已完成工作。

材料或设计缺陷将受影响工作返回 Clarify，不通过实现分派重定义目标。Senior 按公共角色合同处理实施选择和范围内澄清，不能覆盖要求、豁免 Verify 或授权受保护动作。必须由用户决定的真实阻塞用普通文字说明，继续独立就绪工作。

每次当前候选通过后，保存结果并调度下一授权就绪单元，不再索取继续指令。所选全部单元核验完成后，一并提交用户审查或开展已授权交付。不为维持调度而擅自集成。

## 返回

在所属执行记录保存实质调度结果：完成单元、基线与候选、报告链接、检查覆盖、修复及受阻依赖。路由与待完成通信留在运行状态。子任务证据归其所有者，父任务保存链接。

逐单元简报实现结果、快速检查次数、独立结论及报告、候选及基线、审查与交付状态、具体剩余阻塞。部分单元受阻时保留完整所选范围。监督完成不表示合并、安装、发布或 Task 关闭。
