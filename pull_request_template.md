## Motivation

What problem does this change solve? Link a related Issue or discussion if one exists.

## Changes

Summarize the affected components or documents and the user-visible changes.

## Verification

List the commands or scenarios you actually ran and their results. State what remains unverified or does not apply, and why. A documentation-only change does not by itself require new tests or a model run.

## Documentation

For behavior changes, note the affected documentation updates. Update affected language pairs or Skill variants together. For a component's functional change, include its required version update. State which reminders do not apply and why.
