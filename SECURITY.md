# Security policy

English | [中文](./SECURITY.zh.md)

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/ruokee/ruokee-agent-kit/security/advisories/new) to report a suspected vulnerability in this repository. Ruokee receives, assesses, and coordinates the handling of reports. Keep undisclosed vulnerability details out of public Issues and pull requests.

Include the information you have:

- The affected component or repository file.
- The component version or repository commit.
- Relevant operating system, runtime, or host details.
- Steps or a small example that reproduces the problem.
- The security impact you observed and who may be affected.

Remove credentials and unrelated personal information from examples and logs. You do not need to establish which component caused the problem before reporting.

## Scope

This policy covers the first-party code, scripts, and Skills maintained in this repository. If a problem originates solely in a host product, report it to that project's maintainers. If the source is unclear, describe what you observed here so its ownership can be assessed.

Problems caused by this repository's Skills can be reported. An unwanted model response alone does not establish a vulnerability in this repository; describe the concrete security impact you observed.

## Supported versions

Security fixes target the current contents of `main`. Reports about older versions are welcome, but historical-version backports are not promised. Update to a version or commit that includes the fix.

This policy does not change any component's host maintenance lower bound.

## Handling reports

Ruokee follows report notifications and reviews the information provided. Further communication stays in the same GitHub private report. Ruokee may request more information, accept the report and collaborate on a fix, or explain why the report is not accepted. Undisclosed details stay out of public Issues and pull requests.

There is no fixed response or fix deadline.

## Disclosure

Ruokee coordinates disclosure with the reporter case by case, usually after a fix or mitigation is available. Urgent risks may require a different schedule, discussed with the reporter.

There is no fixed disclosure period or requirement to keep a report confidential indefinitely.

## Other reports

Use [Issues](https://github.com/ruokee/ruokee-agent-kit/issues) for non-security problems and suggestions. Report conduct concerns through the [Code of Conduct's reporting channel](./CODE_OF_CONDUCT.md#reporting).
