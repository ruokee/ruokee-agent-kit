# 子代理

[English](./subagent.md) | 中文 | [词典](./README.zh.md)

子代理（subagent）是由另一个 Agent 启动的 Agent，拥有自己的上下文、任务和结果边界。

## 机制

父 Agent 定义一个自包含的任务：目标、范围、验收、输入和子代理可以使用的工具。子代理在自己的上下文中运行并返回结果。父 Agent 保留计划和最终判断，并整合结果。

## 示例

父 Agent 把文件调研拆成独立切片，每个子代理负责一个切片，等全部结果返回后整合证据。

## 避免

避免把顶层计划或整体交付委派出去。避免假定子代理能看到父 Agent 的对话。避免让多个子代理同时修改同一个文件或契约。
