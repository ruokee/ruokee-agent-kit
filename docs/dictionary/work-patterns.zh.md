# 工作模式

[English](./work-patterns.md) | 中文 | [词典](./README.zh.md)

工作模式（work patterns）是在人员与 Agent 之间分工的方式：人在回路、AFK、质询和原型验证。

## 机制

这些模式在人员何时介入上不同。质询在工作前确定需求。原型验证在正式实现前降低未知。人在回路让人员在会话期间持续参与。AFK 让工作无人值守继续，只返回需要人员决定的事项。一个任务可以组合多种模式。

## 示例

一个功能先做质询，对风险较高的集成做原型验证，机械性切片以 AFK 方式继续，合入前暂停等待人工审查。

## 避免

避免在需要用户授权时选择 AFK。避免用质询询问代码或文档已经能够回答的问题。避免把原型当作交付物。

## 人在回路

人在回路（human-in-the-loop）是人员在会话期间持续参与，在既定节点审查、纠正方向或作出决定的工作模式。

## AFK

AFK 是让 Agent 无人值守运行、只返回需要人员决定的事项的工作模式。

## 质询

质询（grilling）是每轮最多提出三个独立问题、不设轮次上限、记录每个回答，并在总结确认后结束，用户也可以提前结束的访谈模式。

## 原型验证

原型验证（prototyping）是在正式实现前构建小型可运行版本，以解决不确定性的工作模式。
