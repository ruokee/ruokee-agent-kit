# Agent

[English](./agent.md) | 中文 | [词典](./README.zh.md)

Agent 是在 Harness 中工作的模型：Harness 提供工具和指令、持有上下文，并运行工具循环。

## 机制

Agent 运行一个循环。Harness 把当前上下文发送给模型，模型返回文本或请求工具调用，Harness 执行这些调用并追加结果，循环持续到模型停止。

## 示例

聊天产品和编码 Harness 可以调用同一个模型，却表现出不同行为，因为它们的工具、提示和上下文管理不同。

## 避免用词

避免把模型称为 Agent。避免把聊天产品称为模型。需要区分时，避免把 Harness 和宿主当作同义词。

## 模型

模型（model）是 Agent 调用的 token 预测器。每个请求彼此独立：输入 token，输出 token。模型不打开文件、不执行命令，也不在请求之间保留状态。

## Harness

Harness 是模型周围的运行时层。它提供工具和系统提示，管理上下文窗口，落实权限，并运行执行工具调用、回传结果的循环。

## 宿主

宿主（host）是发现、加载并运行组件的 Agent Harness 或产品。在本仓库中，宿主包或技能安装面向特定的 Harness。
