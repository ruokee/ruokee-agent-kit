# 技能

[English](./skill.md) | 中文 | [词典](./README.zh.md)

技能（Skill）是宿主可以发现并加载的自包含指令组件，包含 `SKILL.md` 和辅助文件。

## 机制

技能是指令，不是加载到宿主进程中的代码。宿主在技能根目录发现它，并在任务匹配或用户显式调用时加载指令。英文基础版位于 `skills/<name>/`，中文变体位于 `variants/zh/skills/<name>/`，两者具有相同的文件集和范围。安装会把选中的变体复制到 `<skill root>/<name>/`。

技能可以包含参考文档、工作流、示例和术语表。它必须自包含：文件只引用自身目录内的文件。

## 示例

`code-quality` 是 Agent 调用技能，`grill-me` 是用户调用技能。两者都带有自己的 `SKILL.md` 和辅助文件。

## 避免用词

避免用「插件」指技能。插件是宿主扩展，不是指令组件。

## 技能根目录

技能根目录（skill root）是宿主发现已安装技能的目录，形式为 `<skill root>/<name>/`。安装器把技能复制到那里，不带源目录专用的 `variants/zh/` 前缀。

## 用户调用

用户调用（user-invoked）是需要用户显式命令才会加载的技能调用方式，例如 `/skill:grill-me`。模型不会自行加载这类技能。

## Agent 调用

Agent 调用（Agent-invoked）是在任务匹配时允许模型自行加载技能的调用方式。技能描述说明它适用的场景。
