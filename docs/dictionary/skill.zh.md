# 技能

[English](./skill.md) | 中文 | [词典](./README.zh.md)

技能（Skill）是宿主可以发现并加载的一组指令，包含 `SKILL.md` 和辅助文件。公开分发的 Skill 是自包含组件，内部项目 Skill 属于仓库维护材料。

## 机制

技能是指令，不是加载到宿主进程中的代码。宿主在技能根目录发现它，并在任务匹配或用户显式调用时加载指令。语言变体保持相同文件集和范围，安装选择完整变体。

公开 Skill 可以包含参考文档、工作流、示例和术语表，其文件只引用自身目录内的文件。内部项目 Skill 可以读取所维护的项目文档，不是公开安装源，由[仓库规格](../../.agents/spec/repository.zh.md)覆盖。

## 示例

`code-quality` 是 Agent 调用技能，`grill-me` 是用户调用技能。两者都带有自己的 `SKILL.md` 和辅助文件。

## 避免用词

避免用「插件」指技能。插件是宿主扩展，不是指令组件。

## 技能根目录

技能根目录（skill root）是容纳已安装技能目录的父目录，每个技能位于 `<skill root>/<name>/`。源码专用布局前缀不属于安装身份。

## 用户调用

用户调用（user-invoked）是需要用户显式命令才会加载的技能调用方式，例如 `/skill:grill-me`。模型不会自行加载这类技能。

## Agent 调用

Agent 调用（Agent-invoked）是在任务匹配时允许模型自行加载技能的调用方式。技能描述说明它适用的场景。
