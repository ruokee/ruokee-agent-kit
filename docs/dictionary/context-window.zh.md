# 上下文窗口

[English](./context-window.md) | 中文 | [词典](./README.zh.md)

上下文窗口（context window）是模型在单个请求中能够处理的最大 token 数，由输入和输出共用。

## 机制

每个模型有固定的窗口。Harness 为单个请求发送的所有内容都占用这个空间：指令、较早的消息、工具输出和当前输入。当下一个请求将超过窗口时，Harness 必须先缩短或丢弃内容再发送。

## 示例

长时间的编码会话可能耗尽窗口。Harness 把较早的回合压缩成摘要，保留最近的消息和相关文件，用更小的上下文继续。

## 避免

避免用「上下文窗口」指当前对话中的内容；那是上下文。窗口是容量。

## 上下文

上下文（context）是模型在单个请求中可以使用的 token：指令、对话、工具结果、检索材料和当前输入。

## token

token 是模型消费和产生的最小文本单位。文本在预测前被拆分成 token，窗口限制的就是 token 数量。

## 压缩

压缩（compaction）是用更短的摘要替换部分对话，让剩余上下文适合窗口。压缩保留后续工作需要的内容，丢弃不再重要的细节。
