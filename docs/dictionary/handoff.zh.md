# 交接

[English](./handoff.md) | 中文 | [词典](./README.zh.md)

交接（handoff）是让全新会话或 Agent 在没有先前对话的情况下继续工作的持久记录。

## 机制

交接说明目标、已接受的决定、当前状态、证据、下一步、稳定约束和阻塞。它保存在下一个会话可以访问的持久位置，例如任务材料文件。下一个会话读取交接，而不是旧对话记录；旧记录仍可查阅，但不是工作上下文。

## 示例

会话接近上下文上限。它把当前状态和下一步写入交接，新会话从该文件继续。

## 避免

避免把交接当作进度日志。避免记录会话权限快照或临时会话细节。避免让下一步行动含糊。
