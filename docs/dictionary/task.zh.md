# 任务

[English](./task.md) | 中文 | [词典](./README.zh.md)

任务（Task）是由 tk 管理的、项目内长期存在的工作单元，带有材料目录和生命周期。

## 机制

tk 把任务保存在 `.tk/` 下，包含托管的身份、记录稳定目标和边界的 `TASK.md`，以及保存分析、计划、决定和证据的材料目录。WAL 按顺序记录活动。任务状态为 `planning`、`open` 或 `closed`；关闭任务需要维护者当次明确确认。

任务不是单个待办项。当工作需要跨步骤、跨会话或跨 Agent 保留，或者其状态在交接中有意义时，使用任务。

## 材料

材料（material）是任务材料目录中的文件，记录该任务的分析、计划、决定或证据。`TASK.md` 用于稳定的长期内容，工作细节放在单独的材料文件中。

## 示例

一个跨会话的功能任务把需求写在 `TASK.md` 中，把计划和验证报告放在不同的材料文件里。

## 避免用词

避免用「工单」指 tk 任务。避免把临时会话状态或临时权限写入任务材料。
